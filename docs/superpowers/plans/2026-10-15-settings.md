# Settings Implementation Plan

**Goal:** Replace the temporary `/settings` page with the full settings screen from the `Settings` design: profile (name, email) saved through a new mock `PUT /v1/me`, currency and region (base currency, language, financial month start, theme) saved on change, notification preferences, data actions (CSV export, import "coming soon", category manager, account deletion behind a strong confirmation) and, in mock mode only, a demo section (switch demo user, reset demo data, simulate network errors).

**Architecture:** A new `app/features/settings` slice owns its API module (`PUT /v1/me` and the `/v1/demo/*` endpoints), query keys, composables, the profile Vuelidate schema, pure option builders and one component per section. The page `app/pages/settings.vue` composes the sections with `CategoryManagerDialog` (categories feature) and `useTransactionExport()` (transactions feature); features never import each other. Settings changes reuse `useUpdateSettings()` from `app/shared/user` (which already invalidates through the `settings` entry); a shared mutation key lets every section disable its controls while any settings save runs. The mock backend gains `PUT /v1/me` with FluentValidation-style field errors; no new tables.

**Tech stack:** Nuxt 4, TypeScript strict, TanStack Query (`useQuery`, `useMutation`, `useIsMutating`), PrimeVue 4.5 (`Select`, `ToggleSwitch`, `Dialog`, `ConfirmDialog`, `Button`, `InputText`, `Skeleton`, `Toast`), Vuelidate, `@nuxtjs/i18n` 10 (`setLocale`), Tailwind 4, Bun (`bun test`), Playwright, Biome.

**Spec:** `docs/superpowers/specs/2026-10-15-frontend-mocks-design.md` (section 3 Settings row, section 4 forms and errors, section 5 testing and step 9), the design `Settings` (`/home/jaloqa/dock.mita-work/design/Settings.dc.html`) and the stage decisions in `/home/jaloqa/dock.mita-work/scripts/set-decisions.md`.

## Review Focus

- A save that fails (simulated network error) on a select or a switch: an error toast, the control shows the stored value again, and for the language nothing switches (URL and locale unchanged). Pinned in Task 6 ("a failed save ...").
- Two settings changed in quick succession in different sections: the second must not overwrite the first with stale values; every settings control is disabled while any settings save runs (`useIsMutating` on the shared key). Pinned in Task 5 (the other switches are disabled while one saves).
- Email typed with spaces or different case: the profile trims it, uniqueness is case-insensitive against the other user, the server error lands on the field with focus. Pinned in Task 2 (unit) and Task 4 (E2E with Oleh's address).
- The profile form after a demo switch, a reset or an account deletion shows the server's current user, never stale edits. Pinned in Task 6 (switch, reset) and Task 5 (delete).
- Month start changed while another screen is cached: the budgets period range follows without a reload, whatever today's date. Pinned in Task 4 (Day 10 vs Day 1 range computed in the test).

## Adaptations of the stage decisions

- Profile name limit is 40, not 60: `validation.nameTooLong` already reads "Use at most 40 characters." in every locale and is shared with accounts, categories and goals; a 60 limit would show a wrong message.
- The profile form re-initialises whenever the server user changes (not only its id): a reset or an account deletion keeps the id `usr_anna` but must restore "Anna Nowak". Unchanged refetches keep the same object (structural sharing), so edits are not overwritten by background refetches.
- `useUpdateSettings` gets `mutationKey: userKeys.settings`, and `useSettingsChange` disables the controls of every section through `useIsMutating`, so two sections cannot PUT stale copies of the settings concurrently.
- The demo user `Select` shows `loading` instead of being disabled while switching, so focus stays on it.
- Two small feature components beyond the listed ones: `SettingsCard` (section chrome, used five times) and `SettingsToggleRow` (labelled switch row with a 44px hit area, used by notifications and demo).
- Russian month start label is "{day}-е число" (the design's wording, grammatically identical for 1–28); the other locales use "Day/Dzień/День {day}".
- Month start E2E picks "Day 10" (the period always changes from the calendar month, whatever today is) and asserts the budgets period range (`PeriodSwitcher` `title`) computed in the test. Mobile has no Budgets or Settings link in the bottom navigation, so mobile reaches budgets through Overview → "Budgets by period" and returns with history back (still no reload).
- The simulate-errors switch confirms with the generic `settings.saved` toast.

```ts
import {
  type Locale,
  locales,
  type NotificationPrefs,
  type SettingsDto,
  type ThemePreference,
  themePreferences,
  type UpdateMeRequest,
  type UserDto,
} from '../../app/shared/api/contract'
import { type Currency, currencies } from '../../app/shared/money/money'
import type { MonthStart } from '../../app/shared/period/period'
import type { MockDb, SettingsRow } from '../db'
import { badRequest, notFound } from '../errors'
import type { MockRouter } from '../router'
import { collectErrors, isMissing, objectBody } from '../validation'

const PROFILE_NAME_MAX = 40
const EMAIL_MAX = 254
const EMAIL_PATTERN = /^[^\s@]+@[^\s@]+\.[^\s@]+$/

const notificationKeys: (keyof NotificationPrefs)[] = ['budgetLimit', 'dailyReminder', 'weeklyReport', 'goals']

const findSettings = (db: MockDb, userId: string): SettingsRow =>
  db.state.settings.find((row) => row.userId === userId) ?? notFound()

export const toSettingsDto = ({ userId: _userId, ...settings }: SettingsRow): SettingsDto => settings

const isMonthStart = (value: unknown): value is MonthStart =>
  value === 'lastWorkingDay' || (typeof value === 'number' && Number.isInteger(value) && value >= 1 && value <= 28)

const isNotifications = (value: unknown): value is NotificationPrefs =>
  typeof value === 'object' &&
  value !== null &&
  notificationKeys.every((key) => typeof (value as Record<string, unknown>)[key] === 'boolean')

function validateSettings(body: unknown): SettingsDto {
  const input = (typeof body === 'object' && body !== null ? body : {}) as Record<string, unknown>
  const errors: Record<string, string[]> = {}
  const check = (field: string, valid: boolean) => {
    if (input[field] === undefined || input[field] === null) errors[field] = ['validation.required']
    else if (!valid) errors[field] = ['validation.invalidValue']
  }
  check('baseCurrency', currencies.includes(input.baseCurrency as Currency))
  check('locale', locales.includes(input.locale as Locale))
  check('monthStartDay', isMonthStart(input.monthStartDay))
  check('theme', themePreferences.includes(input.theme as ThemePreference))
  check('notifications', isNotifications(input.notifications))
  if (Object.keys(errors).length > 0) badRequest(errors)
  const notifications = input.notifications as NotificationPrefs
  return {
    baseCurrency: input.baseCurrency as Currency,
    locale: input.locale as Locale,
    monthStartDay: input.monthStartDay as MonthStart,
    theme: input.theme as ThemePreference,
    notifications: Object.fromEntries(notificationKeys.map((key) => [key, notifications[key]])) as NotificationPrefs,
  }
}

const emailTakenBy = (db: MockDb, userId: string, email: string): boolean =>
  db.state.users.some((user) => user.id !== userId && user.email.toLowerCase() === email.toLowerCase())

function validateProfile(db: MockDb, userId: string, body: unknown): UpdateMeRequest {
  const { name, email } = objectBody(body)
  const errors = collectErrors()
  if (isMissing(name)) errors.add('name', 'validation.required')
  else if (typeof name !== 'string') errors.add('name', 'validation.invalidValue')
  else if (name.trim().length > PROFILE_NAME_MAX) errors.add('name', 'validation.nameTooLong')
  if (isMissing(email)) errors.add('email', 'validation.required')
  else if (typeof email !== 'string') errors.add('email', 'validation.invalidValue')
  else {
    const address = email.trim()
    if (address.length > EMAIL_MAX || !EMAIL_PATTERN.test(address)) errors.add('email', 'validation.invalidEmail')
    else if (emailTakenBy(db, userId, address)) errors.add('email', 'validation.emailTaken')
  }
  errors.throwIfAny()
  return { name: (name as string).trim(), email: (email as string).trim() }
}

export function registerUserHandlers(router: MockRouter) {
  router.on(
    'GET',
    '/v1/me',
    ({ db, userId }): UserDto => db.state.users.find((user) => user.id === userId) ?? notFound(),
  )

  router.on('PUT', '/v1/me', ({ db, userId, body }): UserDto => {
    const user = db.state.users.find((row) => row.id === userId) ?? notFound()
    Object.assign(user, validateProfile(db, userId, body))
    db.save()
    return user
  })

  router.on('GET', '/v1/settings', ({ db, userId }) => toSettingsDto(findSettings(db, userId)))

  router.on('PUT', '/v1/settings', ({ db, userId, body }) => {
    const row = findSettings(db, userId)
    Object.assign(row, validateSettings(body))
    db.save()
    return toSettingsDto(row)
  })
}
```

```ts
import { helpers, required } from '@vuelidate/validators'

export const PROFILE_NAME_MAX = 40
export const EMAIL_MAX = 254

export type ProfileForm = { name: string; email: string }

type Translate = (key: string) => string

const EMAIL_PATTERN = /^[^\s@]+@[^\s@]+\.[^\s@]+$/

const isBlank = (value: unknown): boolean =>
  value === undefined || value === null || (typeof value === 'string' && value.trim() === '')

export const fitsProfileName = (value: unknown): boolean =>
  typeof value !== 'string' || value.trim().length <= PROFILE_NAME_MAX

export const isEmailAddress = (value: unknown): boolean => {
  if (isBlank(value)) return true
  if (typeof value !== 'string') return false
  const address = value.trim()
  return address.length <= EMAIL_MAX && EMAIL_PATTERN.test(address)
}

export const profileRules = (t: Translate) => {
  const requiredField = helpers.withMessage(() => t('validation.required'), required)
  return {
    name: {
      required: requiredField,
      maxLength: helpers.withMessage(() => t('validation.nameTooLong'), fitsProfileName),
    },
    email: {
      required: requiredField,
      format: helpers.withMessage(() => t('validation.invalidEmail'), isEmailAddress),
    },
  }
}
```

```ts
  new Intl.NumberFormat(locale, { style: 'currency', currency, currencyDisplay: 'narrowSymbol' })
    .formatToParts(0)
    .find((part) => part.type === 'currency')?.value ?? currency

export const currencyLabel = (currency: Currency, locale: string): string =>
  `${currency} — ${currencySymbol(currency, locale)}`
```

```ts
import { useIsMutating } from '@tanstack/vue-query'
import type { SettingsDto } from '~/shared/api/contract'
import { userKeys } from '~/shared/user/keys'
import { useUpdateSettings, useUserSettings } from '~/shared/user/useUserSettings'

export function useSettingsChange() {
  const { t } = useI18n()
  const notify = useNotify()
  const { settings, isPending, isError, refetch } = useUserSettings()
  const update = useUpdateSettings()
  const mutating = useIsMutating({ mutationKey: userKeys.settings })
  const saving = computed(() => mutating.value > 0)
  const draft = ref<Partial<SettingsDto>>({})

  function change(patch: Partial<SettingsDto>, apply?: () => unknown) {
    if (saving.value) return
    draft.value = patch
    update.mutate(
      { ...settings.value, ...patch },
      {
        onSuccess: async () => {
          await apply?.()
          draft.value = {}
          notify.success(t('settings.saved'))
        },
        onError: (error) => {
          draft.value = {}
          notify.error(error)
        },
      },
    )
  }

  return { settings, isPending, isError, refetch, draft, saving, change }
}
```

```vue
<script setup lang="ts">
import { useVuelidate } from '@vuelidate/core'
import { useCurrentUser } from '~/shared/user/useCurrentUser'
import { type ProfileForm, profileRules } from '../schemas/profileSchema'

const { t } = useI18n()
const notify = useNotify()
const server = useServerErrors()
const { user, isPending, isError, refetch } = useCurrentUser()
const update = useProfileUpdate()

const fields = ['name', 'email'] as const
type Field = (typeof fields)[number]

const form = reactive<ProfileForm>({ name: '', email: '' })
const v$ = useVuelidate(profileRules(t), form)
const formEl = ref<HTMLFormElement | null>(null)

watch(
  user,
  (current) => {
    if (!current) return
    form.name = current.name
    form.email = current.email
    server.clear()
    v$.value.$reset()
  },
  { immediate: true },
)

const errorsOf = (field: Field) => [
  ...v$.value[field].$errors.map((error) => String(unref(error.$message))),
  ...server.messages(field),
]

function touch(field: Field) {
  v$.value[field].$touch()
  server.clear(field)
}

async function showServerErrors(error: unknown) {
  if (server.apply(error, fields)) {
    await nextTick()
    focusFirstInvalid(formEl.value)
  } else notify.error(error)
}

async function submit() {
  server.clear()
  if (!(await v$.value.$validate())) {
    await nextTick()
    focusFirstInvalid(formEl.value)
    return
  }
  update.mutate(
    { name: form.name.trim(), email: form.email.trim() },
    { onSuccess: () => notify.success(t('settings.profile.saved')), onError: showServerErrors },
  )
}
</script>

<template>
```

```vue
import type { Currency } from '~/shared/money/money'

import { currencyOptions, monthStartOptions } from '../utils/options'

const { t, locale, locales, setLocale } = useI18n()
const { preference } = useColorMode()
const { settings, isPending, isError, refetch, draft, saving, change } = useSettingsChange()

const currencies = computed(() => currencyOptions(locale.value))
const languages = computed(() => locales.value.map((item) => ({ value: item.code, label: item.name ?? item.code })))
const monthStarts = computed(() =>
  monthStartOptions((day) => t('settings.region.monthStartDay', { day }), t('settings.region.lastWorkingDay')),
)
const themes = computed(() => themePreferences.map((theme) => ({ value: theme, label: t(`shared.theme.${theme}`) })))

const shown = computed(() => ({
  baseCurrency: draft.value.baseCurrency ?? settings.value.baseCurrency,
  locale: draft.value.locale ?? locale.value,
  monthStartDay: draft.value.monthStartDay ?? settings.value.monthStartDay,
  theme: draft.value.theme ?? preference.value,
}))

function selectCurrency(baseCurrency: Currency) {
  if (baseCurrency !== shown.value.baseCurrency) change({ baseCurrency })
}

function selectLocale(code: Locale) {
  if (code !== shown.value.locale) change({ locale: code }, () => setLocale(code))
}

function selectMonthStart(monthStartDay: MonthStart) {
  if (monthStartDay !== shown.value.monthStartDay) change({ monthStartDay })
}

  if (theme === shown.value.theme) return
  change({ theme }, () => {
    preference.value = theme

}
```

```vue
<script setup lang="ts">
const { t } = useI18n()
const notify = useNotify()
const confirm = useConfirm()
const { state, isPending, isError, refetch } = useDemoState()
const { switchUser, reset, simulateErrors } = useDemoMutations()

const requestedUser = ref<string>()
const requestedErrors = ref<boolean>()

const users = computed(() => (state.value?.users ?? []).map((user) => ({ value: user.id, label: user.name })))
const activeUser = computed(() => requestedUser.value ?? state.value?.activeUserId)
const errorsSimulated = computed(() => requestedErrors.value ?? state.value?.simulateErrors ?? false)

function selectUser(userId: string) {
  if (switchUser.isPending.value || userId === state.value?.activeUserId) return
  const name = users.value.find((user) => user.value === userId)?.label ?? ''
  requestedUser.value = userId
  switchUser.mutate(userId, {
    onSuccess: () => notify.success(t('settings.demo.switched', { name })),
    onError: (error) => notify.error(error),
    onSettled: () => {
      requestedUser.value = undefined
    },
  })
}

function confirmReset() {
  confirm.require({
    header: t('settings.demo.resetTitle'),
    message: t('settings.demo.resetMessage'),
    acceptLabel: t('settings.demo.reset'),
    rejectLabel: t('shared.actions.cancel'),
    acceptProps: { severity: 'danger' },
    rejectProps: { severity: 'secondary', outlined: true },
    accept: () =>
      reset.mutate(undefined, {
        onSuccess: () => notify.success(t('settings.demo.resetDone')),
        onError: (error) => notify.error(error),
      }),
  })
}

function setSimulateErrors(enabled: boolean) {
  if (simulateErrors.isPending.value) return
  requestedErrors.value = enabled
  simulateErrors.mutate(enabled, {
    onSuccess: () => notify.success(t('settings.saved')),
    onError: (error) => notify.error(error),
    onSettled: () => {
      requestedErrors.value = undefined
    },
  })
}
```
