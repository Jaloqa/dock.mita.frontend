# Accounts, Transfers and Rates Implementation Plan

**Goal:** Deliver accounts with backend-computed balances, transfers between accounts (including cross-currency ones with their own rate), a global exchange-rate table, and the `/accounts` screen from `Accounts.dc.html`, plus the shared account and rate data that later features use.

**Architecture:** The mock backend gains three tables (`rates`, `accounts`, `transfers`) and handlers for `/v1/rates`, `/v1/accounts`, `/v1/transfers`. Balances come from a ledger: opening balance plus the movements every registered ledger source reports (transfers now; transactions add their source in stage 4). On the frontend, `app/shared/accounts` and `app/shared/rates` hold the read side other features reuse (account pickers, conversion into the base currency); `app/features/accounts` owns the screen, dialogs and mutations.

**Tech Stack:** Nuxt 4, TypeScript strict, TanStack Query (`@tanstack/vue-query`), Vuelidate, PrimeVue 4 (`Dialog`, `Select`, `SelectButton`, `InputNumber`, `InputText`, `DatePicker`, `Toast`, `ConfirmDialog`, `Skeleton`), vue-i18n, Tailwind 4, Bun (`bun test`), Playwright, Biome.

**Spec:** `docs/superpowers/specs/2026-10-15-frontend-mocks-design.md` (section 1 `Account`, `Transfer`, `Rate` and rules; section 2 endpoints; section 3 Accounts screen; section 4 forms and errors; section 5 step 2).

## Global Constraints

- Code, identifiers, commit messages in English; no comments except for a genuinely controversial decision; no tool attribution and no `Co-Authored-By` trailers in commits or files.
- Amounts are integers in minor units; formatting only through `useMoney().format` / `MoneyText` (`n()` with the currency).
- API paths start with `/v1/`; errors are RFC 9457 ProblemDetails; validation messages are i18n keys under `validation.*`.
- The frontend never sends `userId`; every handler filters by the session user; a foreign or missing id returns `404`; a referenced foreign account returns `400` with a field error.
- Balances are computed by the mock backend only; the frontend never computes a balance (it only converts balances into the base currency for the total and the distribution).
- Every user-facing string goes through i18n with keys in `en`, `pl`, `ru`, `uk` (the parity test enforces it); dates and numbers through `d()` / `n()`.
- Consumers of `useUserSettings` must not format money with the PLN fallback while settings are pending or errored: gate on `isPending` / `isError` (skeleton / `ErrorState`).
- The UI never shows `ApiError.title` raw: unknown errors map by status to `shared.error.*` keys, field errors are shown through their i18n keys.
- Data queries run on the client only in mock mode (already enforced) — no `suspense()` or server prefetch.
- Accessibility: semantic elements, labels for every input, `aria-invalid` + `aria-describedby` on invalid fields, focus moves to the first invalid field on submit, touch targets at least 44px.
- Only libraries from `docs/STACK.md`; PrimeVue stays on 4.x; components use design tokens (`bg-surface`, `text-muted`, `bg-deep`, …), never raw hex values.
- Code under `mocks/`, `app/shared/{money,period}`, `app/shared/api/{contract,problem,errorMessage}.ts`, `app/shared/rates/convert.ts` and `app/features/accounts/{utils,schemas}` uses plain relative imports (no Nuxt auto-imports, no `~` alias) so it runs in Bun.
- Biome and `nuxt typecheck` must pass before every commit.

## Review Focus

- A rate is requested for a date the table does not hold (after the seed day, before the first day, a weekend gap after a stored database ages) — the nearest earlier day is used, or the first day when the date is before the table. Pinned in Task 1.
- The browser still holds a mock database saved by the foundation stage (no `rates`, `accounts`, `transfers`) — the app starts from the new seed instead of crashing. Pinned in Task 1.
- A cross-currency transfer so small that the converted amount rounds to zero — rejected with a field error instead of storing a zero credit. Pinned in Task 3.
- The user corrects the prefilled exchange rate, then the rate query refetches or another field changes — the corrected rate is kept and used for the preview and the request. Pinned in Task 7 (E2E).
- An account with a negative balance (overdraft) — the total includes it, the distribution leaves it out, and no `NaN` or negative bar width appears. Pinned in Task 5.

```ts
export const isIsoDate = (value: unknown): value is string =>
  typeof value === 'string' && /^\d{4}-\d{2}-\d{2}$/.test(value) && toIsoDate(parseIsoDate(value)) === value

export const fromLocalDate = (date: Date): string =>
  `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}`

export const toLocalDate = (iso: string): Date => {
  const [year, month, day] = iso.split('-').map(Number)
  return new Date(year ?? 0, (month ?? 1) - 1, day ?? 1)
}
```

```ts
export const objectBody = (body: unknown): Record<string, unknown> =>
  typeof body === 'object' && body !== null && !Array.isArray(body) ? (body as Record<string, unknown>) : {}

export const isMissing = (value: unknown): boolean =>
  value === undefined || value === null || (typeof value === 'string' && value.trim() === '')

export const isCurrency = (value: unknown): value is Currency => currencies.includes(value as Currency)

export function collectErrors() {
  const errors: Record<string, string[]> = {}
  return {
    add: (field: string, code: string) => {
      errors[field] ??= [code]
    },
    throwIfAny: () => {
      if (Object.keys(errors).length > 0) badRequest(errors)
    },
  }
}
```

```ts
import type { Currency } from '../app/shared/money/money'
import type { RateRow } from './db'

export const roundRate = (value: number): number => Math.round(value * 1e6) / 1e6

function plnValue(rows: readonly RateRow[], date: string, currency: Currency): number | undefined {
  if (currency === 'PLN') return 1
  let earliest: RateRow | undefined
  let latestBefore: RateRow | undefined
  for (const row of rows) {
    if (row.from !== currency || row.to !== 'PLN') continue
    if (!earliest || row.date < earliest.date) earliest = row
    if (row.date <= date && (!latestBefore || row.date > latestBefore.date)) latestBefore = row
  }
  return (latestBefore ?? earliest)?.value
}

export function rateOn(rows: readonly RateRow[], date: string, from: Currency, to: Currency): number {
  if (from === to) return 1
  const fromValue = plnValue(rows, date, from)
  const toValue = plnValue(rows, date, to)
  if (fromValue === undefined || toValue === undefined) throw new Error(`No rate for ${from}/${to}`)
  return roundRate(fromValue / toValue)
}
```

```ts
import type { Currency } from '../../app/shared/money/money'
import { addDaysIso } from '../../app/shared/period/period'
import type { RateRow } from '../db'
import { roundRate } from '../rates'

type Quoted = Exclude<Currency, 'PLN'>

const quoted: readonly Quoted[] = ['EUR', 'USD', 'UAH']
const level: Record<Quoted, number> = { EUR: 4.27, USD: 3.93, UAH: 0.0952 }
const phase: Record<Quoted, number> = { EUR: 0, USD: 1.7, UAH: 3.1 }

export const RATE_HISTORY_DAYS = 183

const dayNumber = (iso: string): number => Date.parse(`${iso}T00:00:00Z`) / 86_400_000

export function plnRate(currency: Quoted, date: string): number {
  const day = dayNumber(date)
  const drift =
    0.018 * Math.sin(day / 31 + phase[currency]) +
    0.006 * Math.sin(day / 8.3 + 2 * phase[currency]) +
    0.001 * Math.sin(day * 1.37 + phase[currency])
  return roundRate(level[currency] * (1 + drift))
}

export const seedRates = (today: string): RateRow[] =>
  quoted.flatMap((currency) =>
    Array.from({ length: RATE_HISTORY_DAYS + 1 }, (_, index): RateRow => {
      const date = addDaysIso(today, index - RATE_HISTORY_DAYS)
      return { date, from: currency, to: 'PLN', value: plnRate(currency, date) }
    }),
  )
```

The value is a pure function of the date, so a stored table and a fresh seed agree on every shared day.

```ts
import type { RateDto } from '../../app/shared/api/contract'
import { type Currency, currencies } from '../../app/shared/money/money'
import { isIsoDate, todayIso } from '../../app/shared/period/period'
import { rateOn } from '../rates'
import type { MockRouter } from '../router'
import { collectErrors, isCurrency } from '../validation'

export function registerRateHandlers(router: MockRouter) {
  router.on('GET', '/v1/rates', ({ db, query }): RateDto[] => {
    const errors = collectErrors()
    if (query.date !== undefined && !isIsoDate(query.date)) errors.add('date', 'validation.invalidValue')
    if (query.from !== undefined && !isCurrency(query.from)) errors.add('from', 'validation.invalidValue')
    if (query.to !== undefined && !isCurrency(query.to)) errors.add('to', 'validation.invalidValue')
    errors.throwIfAny()
    const date = query.date ?? todayIso()
    const sources: readonly Currency[] = query.from ? [query.from as Currency] : currencies
    const targets: readonly Currency[] = query.to ? [query.to as Currency] : currencies
    return sources.flatMap((from) =>
      targets
        .filter((to) => to !== from)
        .map((to) => ({ date, from, to, value: rateOn(db.state.rates, date, from, to) })),
    )
  })
}
```

```ts
import type { Page } from '../app/shared/api/contract'
import { collectErrors } from './validation'

const positiveInteger = (value: string | undefined, fallback: number): number | undefined => {
  if (value === undefined) return fallback
  const parsed = Number(value)
  return Number.isInteger(parsed) && parsed >= 1 ? parsed : undefined
}

export function paginate<T>(
  items: readonly T[],
  query: Record<string, string>,
  options: { defaultPageSize: number; maxPageSize: number },
): Page<T> {
  const page = positiveInteger(query.page, 1)
  const pageSize = positiveInteger(query.pageSize, options.defaultPageSize)
  const errors = collectErrors()
  if (page === undefined) errors.add('page', 'validation.invalidValue')
  if (pageSize === undefined || pageSize > options.maxPageSize) errors.add('pageSize', 'validation.invalidValue')
  errors.throwIfAny()
  const current = page as number
  const size = pageSize as number
  return { items: items.slice((current - 1) * size, current * size), page: current, pageSize: size, total: items.length }
}
```

```ts
import type { MockState } from './db'

export type Movement = { accountId: string; amount: number }

export type Ledger = (state: MockState, userId: string) => Movement[]

export const ledgers: Ledger[] = []

const movementsOf = (state: MockState, userId: string): Movement[] =>
  ledgers.flatMap((ledger) => ledger(state, userId))

export function accountBalances(state: MockState, userId: string): Map<string, number> {
  const balances = new Map(
    state.accounts.filter((account) => account.userId === userId).map((account) => [account.id, account.openingBalance]),
  )
  for (const movement of movementsOf(state, userId)) {
    balances.set(movement.accountId, (balances.get(movement.accountId) ?? 0) + movement.amount)
  }
  return balances
}

export function accountsInUse(state: MockState, userId: string): Set<string> {
  return new Set(movementsOf(state, userId).map((movement) => movement.accountId))
}
```

```ts
import { type AccountDto, type AccountType, accountTypes } from '../../app/shared/api/contract'
import type { Currency } from '../../app/shared/money/money'
import type { AccountRow, MockDb } from '../db'
import { badRequest, notFound } from '../errors'
import { newId } from '../ids'
import { accountBalances, accountsInUse } from '../ledger'
import { paginate } from '../paginate'
import type { MockRouter } from '../router'
import { collectErrors, isCurrency, isMissing, objectBody } from '../validation'

export const ACCOUNT_NAME_MAX = 40
const MAX_AMOUNT = 100_000_000_000

type AccountFields = Pick<AccountRow, 'name' | 'type' | 'currency' | 'openingBalance' | 'cardLast4' | 'archived'>
type Usage = { balances: Map<string, number>; inUse: Set<string> }

const isAccountType = (value: unknown): value is AccountType => accountTypes.includes(value as AccountType)

function validateAccount(body: unknown, existing?: { row: AccountRow; inUse: boolean }): AccountFields {
  const input = objectBody(body)
  const { name, type, currency, openingBalance, cardLast4, archived } = input
  const errors = collectErrors()
  if (isMissing(name)) errors.add('name', 'validation.required')
  else if (typeof name !== 'string') errors.add('name', 'validation.invalidValue')
  else if (name.trim().length > ACCOUNT_NAME_MAX) errors.add('name', 'validation.nameTooLong')
  if (isMissing(type)) errors.add('type', 'validation.required')
  else if (!isAccountType(type)) errors.add('type', 'validation.invalidValue')
  if (isMissing(currency)) errors.add('currency', 'validation.required')
  else if (!isCurrency(currency)) errors.add('currency', 'validation.invalidValue')
  else if (existing?.inUse && currency !== existing.row.currency) errors.add('currency', 'validation.currencyLocked')
  if (isMissing(openingBalance)) errors.add('openingBalance', 'validation.required')
  else if (!Number.isSafeInteger(openingBalance) || Math.abs(openingBalance as number) > MAX_AMOUNT) {
    errors.add('openingBalance', 'validation.invalidValue')
  }
  if (!isMissing(cardLast4) && (typeof cardLast4 !== 'string' || !/^\d{4}$/.test(cardLast4))) {
    errors.add('cardLast4', 'validation.cardLast4')
  }
  if (archived !== undefined && typeof archived !== 'boolean') errors.add('archived', 'validation.invalidValue')
  errors.throwIfAny()
  return {
    name: (name as string).trim(),
    type: type as AccountType,
    currency: currency as Currency,
    openingBalance: openingBalance as number,
    cardLast4: type === 'card' && !isMissing(cardLast4) ? (cardLast4 as string) : null,
    archived: typeof archived === 'boolean' ? archived : (existing?.row.archived ?? false),
  }
}

const usageOf = (db: MockDb, userId: string): Usage => ({
  balances: accountBalances(db.state, userId),
  inUse: accountsInUse(db.state, userId),
})

const toDto = ({ userId: _userId, createdAt: _createdAt, ...row }: AccountRow, usage: Usage): AccountDto => ({
  ...row,
  balance: usage.balances.get(row.id) ?? row.openingBalance,
  inUse: usage.inUse.has(row.id),
})

const ownAccount = (db: MockDb, userId: string, id: string | undefined): AccountRow =>
  db.state.accounts.find((account) => account.id === id && account.userId === userId) ?? notFound()

export function registerAccountHandlers(router: MockRouter) {
  router.on('GET', '/v1/accounts', ({ db, userId, query }) => {
    const usage = usageOf(db, userId)
    const own = db.state.accounts.filter((account) => account.userId === userId)
    return paginate(
      own.map((row) => toDto(row, usage)),
      query,
      { defaultPageSize: 100, maxPageSize: 100 },
    )
  })

  router.on('POST', '/v1/accounts', ({ db, userId, body }) => {
    const row: AccountRow = { id: newId('acc'), userId, createdAt: new Date().toISOString(), ...validateAccount(body) }
    db.state.accounts.push(row)
    db.save()
    return toDto(row, usageOf(db, userId))
  })

  router.on('PUT', '/v1/accounts/:id', ({ db, userId, params, body }) => {
    const row = ownAccount(db, userId, params.id)
    const usage = usageOf(db, userId)
    Object.assign(row, validateAccount(body, { row, inUse: usage.inUse.has(row.id) }))
    db.save()
    return toDto(row, usageOf(db, userId))
  })

  router.on('DELETE', '/v1/accounts/:id', ({ db, userId, params }) => {
    const row = ownAccount(db, userId, params.id)
    if (accountsInUse(db.state, userId).has(row.id)) badRequest({ id: ['validation.accountInUse'] })
    db.state.accounts = db.state.accounts.filter((account) => account.id !== row.id)
    db.save()
  })
}
```

```ts
import type { TransferDto } from '../../app/shared/api/contract'
import { convertMinor } from '../../app/shared/money/money'
import { isIsoDate, todayIso } from '../../app/shared/period/period'
import type { AccountRow, MockDb, TransferRow } from '../db'
import { badRequest } from '../errors'
import { newId } from '../ids'
import { paginate } from '../paginate'
import { rateOn, roundRate } from '../rates'
import type { MockRouter } from '../router'
import { collectErrors, isMissing, objectBody } from '../validation'

export const TRANSFER_NOTE_MAX = 200
const MAX_AMOUNT = 100_000_000_000

type Errors = ReturnType<typeof collectErrors>

export const oneYearAhead = (today: string): string => `${Number(today.slice(0, 4)) + 1}${today.slice(4)}`

function checkAccount(db: MockDb, userId: string, value: unknown, field: string, errors: Errors) {
  if (isMissing(value)) {
    errors.add(field, 'validation.required')
    return undefined
  }
  const account = db.state.accounts.find((row) => row.id === value && row.userId === userId)
  if (!account) errors.add(field, 'validation.unknownAccount')
  else if (account.archived) errors.add(field, 'validation.archivedAccount')
  return account
}

function createTransfer(db: MockDb, userId: string, body: unknown): TransferRow {
  const { date, fromAccountId, toAccountId, fromAmount, rate, note } = objectBody(body)
  const errors = collectErrors()
  if (isMissing(date)) errors.add('date', 'validation.required')
  else if (!isIsoDate(date)) errors.add('date', 'validation.invalidValue')
  else if (date > oneYearAhead(todayIso())) errors.add('date', 'validation.dateTooFar')
  const from = checkAccount(db, userId, fromAccountId, 'fromAccountId', errors)
  const to = checkAccount(db, userId, toAccountId, 'toAccountId', errors)
  if (from && to && from.id === to.id) errors.add('toAccountId', 'validation.sameAccount')
  if (isMissing(fromAmount)) errors.add('fromAmount', 'validation.required')
  else if (!Number.isSafeInteger(fromAmount) || (fromAmount as number) <= 0 || (fromAmount as number) > MAX_AMOUNT) {
    errors.add('fromAmount', 'validation.positiveAmount')
  }
  if (!isMissing(rate) && (typeof rate !== 'number' || !Number.isFinite(rate) || rate <= 0)) {
    errors.add('rate', 'validation.invalidValue')
  }
  if (!isMissing(note) && (typeof note !== 'string' || note.trim().length > TRANSFER_NOTE_MAX)) {
    errors.add('note', 'validation.invalidValue')
  }
  errors.throwIfAny()
  const source = from as AccountRow
  const target = to as AccountRow
  const day = date as string
  const appliedRate =
    source.currency === target.currency
      ? 1
      : typeof rate === 'number'
        ? roundRate(rate)
        : rateOn(db.state.rates, day, source.currency, target.currency)
  const toAmount = convertMinor(fromAmount as number, appliedRate)
  if (toAmount <= 0) badRequest({ rate: ['validation.positiveAmount'] })
  return {
    id: newId('trf'),
    userId,
    date: day,
    fromAccountId: source.id,
    toAccountId: target.id,
    fromAmount: fromAmount as number,
    toAmount,
    rate: appliedRate,
    note: typeof note === 'string' && note.trim() !== '' ? note.trim() : null,
  }
}

const newestFirst = (rows: readonly TransferRow[]): TransferRow[] =>
  rows
    .map((row, index) => ({ row, index }))
    .sort((a, b) => b.row.date.localeCompare(a.row.date) || b.index - a.index)
    .map(({ row }) => row)

const toDto = ({ userId: _userId, ...row }: TransferRow): TransferDto => row

export function registerTransferHandlers(router: MockRouter) {
  router.on('GET', '/v1/transfers', ({ db, userId, query }) => {
    const own = db.state.transfers.filter(
      (row) =>
        row.userId === userId &&
        (query.accountId === undefined || row.fromAccountId === query.accountId || row.toAccountId === query.accountId),
    )
    return paginate(newestFirst(own).map(toDto), query, { defaultPageSize: 20, maxPageSize: 100 })
  })

  router.on('POST', '/v1/transfers', ({ db, userId, body }) => {
    const row = createTransfer(db, userId, body)
    db.state.transfers.push(row)
    db.save()
    return toDto(row)
  })
}
```

```ts
export function rateFrom(rates: readonly RateDto[], from: Currency, to: Currency): number | undefined {
  if (from === to) return 1
  return rates.find((rate) => rate.from === from && rate.to === to)?.value
}

  minor: number,
  from: Currency,
  base: Currency,
  rates: readonly RateDto[],
): number | undefined {
  const rate = rateFrom(rates, from, base)
  return rate === undefined ? undefined : convertMinor(minor, rate)
}
```

```ts
import { useQuery } from '@tanstack/vue-query'
import type { MaybeRefOrGetter } from 'vue'
import type { Currency } from '~/shared/money/money'
import { rateFrom, toBaseAmount } from './convert'
import { rateKeys } from './keys'
import { ratesApi } from './ratesApi'

export function useRates(
  to: MaybeRefOrGetter<Currency>,
  options: { date?: MaybeRefOrGetter<string | undefined>; enabled?: MaybeRefOrGetter<boolean> } = {},
) {
  const api = ratesApi(useApi())
  const query = useQuery({
    queryKey: computed(() => rateKeys.table(toValue(to), toValue(options.date))),
    queryFn: () => api.list({ to: toValue(to), date: toValue(options.date) }),
    enabled: computed(() => toValue(options.enabled ?? true)),
    staleTime: 10 * 60_000,
  })
  const loaded = () => query.data.value

  return {
    rates: computed(() => query.data.value ?? []),
    rateFrom: (from: Currency) => {
      const rates = loaded()
      return from === toValue(to) ? 1 : rates ? rateFrom(rates, from, toValue(to)) : undefined
    },
    toBase: (minor: number, from: Currency) => {
      const rates = loaded()
      return from === toValue(to) ? minor : rates ? toBaseAmount(minor, from, toValue(to), rates) : undefined
    },
    isPending: query.isPending,
    isError: query.isError,
    refetch: query.refetch,
  }
}
```

```ts
import { isApiError } from '~/shared/api/problem'

export function useServerErrors() {
  const { t } = useI18n()
  const errors = ref<Record<string, string[]>>({})

  const clear = (field?: string) => {
    if (field === undefined) errors.value = {}
    else if (field in errors.value) {
      errors.value = Object.fromEntries(Object.entries(errors.value).filter(([key]) => key !== field))
    }
  }

  const apply = (error: unknown, fields: readonly string[], aliases: Record<string, string> = {}): boolean => {
    if (!isApiError(error)) return false
    const known = Object.entries(error.fieldErrors)
      .map(([field, codes]) => [aliases[field] ?? field, codes] as const)
      .filter(([field]) => fields.includes(field))
    errors.value = Object.fromEntries(known)
    return known.length > 0
  }
```

```ts
import type { AccountDto, RateDto } from '../../../shared/api/contract'
import type { Currency } from '../../../shared/money/money'
import { toBaseAmount } from '../../../shared/rates/convert'

export type AccountShare = { id: string; name: string; percent: number }

export function totalInBase(
  accounts: readonly AccountDto[],
  rates: readonly RateDto[],
  base: Currency,
): number | undefined {
  let total = 0
  for (const account of accounts) {
    const amount = toBaseAmount(account.balance, account.currency, base, rates)
    if (amount === undefined) return undefined
    total += amount
  }
  return total
}

export function accountShares(accounts: readonly AccountDto[], rates: readonly RateDto[], base: Currency): AccountShare[] {
  const values = accounts
    .map((account) => ({
      id: account.id,
      name: account.name,
      value: toBaseAmount(account.balance, account.currency, base, rates) ?? 0,
    }))
    .filter((entry) => entry.value > 0)
  const sum = values.reduce((total, entry) => total + entry.value, 0)
  if (sum === 0) return []
  const exact = values.map((entry) => (entry.value * 100) / sum)
  const percents = exact.map((value) => Math.floor(value))
  let missing = 100 - percents.reduce((total, value) => total + value, 0)
  const byRemainder = exact
    .map((value, index) => ({ index, remainder: value - Math.floor(value) }))
    .sort((a, b) => b.remainder - a.remainder)
  for (const { index } of byRemainder) {
    if (missing <= 0) break
    percents[index] = (percents[index] ?? 0) + 1
    missing -= 1
  }
  return values.map((entry, index) => ({ id: entry.id, name: entry.name, percent: percents[index] ?? 0 }))
}
```

```ts
import { useInfiniteQuery } from '@tanstack/vue-query'
import { transferKeys } from '../api/keys'
import { transfersApi } from '../api/transfersApi'

export const TRANSFERS_PAGE_SIZE = 10

export function useTransfers() {
  const api = transfersApi(useApi())
  const query = useInfiniteQuery({
    queryKey: transferKeys.list,
    queryFn: ({ pageParam }) => api.list({ page: pageParam, pageSize: TRANSFERS_PAGE_SIZE }),
    initialPageParam: 1,
    getNextPageParam: (last) => (last.page * last.pageSize < last.total ? last.page + 1 : undefined),
  })

  return {
    items: computed(() => query.data.value?.pages.flatMap((page) => page.items) ?? []),
    isPending: query.isPending,
    isError: query.isError,
    refetch: query.refetch,
    hasNextPage: query.hasNextPage,
    isFetchingNextPage: query.isFetchingNextPage,
    fetchNextPage: () => query.fetchNextPage(),
  }
}
```

```ts
import { useAccounts } from '~/shared/accounts/useAccounts'
import type { AccountDto } from '~/shared/api/contract'
import { useRates } from '~/shared/rates/useRates'
import { useUserSettings } from '~/shared/user/useUserSettings'
import { accountShares, totalInBase } from '../utils/summary'

export function useAccountsSummary() {
  const accounts = useAccounts()
  const settings = useUserSettings()
  const settingsReady = computed(() => !settings.isPending.value && !settings.isError.value)
  const rates = useRates(settings.baseCurrency, { enabled: settingsReady })
  const ready = computed(
    () =>
      settingsReady.value &&
      !rates.isPending.value &&
      !rates.isError.value &&
      !accounts.isPending.value &&
      !accounts.isError.value,
  )
  const active = computed(() => accounts.accounts.value.filter((account) => !account.archived))
  const archived = computed(() => accounts.accounts.value.filter((account) => account.archived))

  return {
    active,
    archived,
    baseCurrency: settings.baseCurrency,
    total: computed(() =>
      ready.value ? totalInBase(active.value, rates.rates.value, settings.baseCurrency.value) : undefined,
    ),
    shares: computed(() =>
      ready.value ? accountShares(active.value, rates.rates.value, settings.baseCurrency.value) : [],
    ),
    baseAmountOf: (account: AccountDto) => (ready.value ? rates.toBase(account.balance, account.currency) : undefined),
    isPending: computed(
      () => accounts.isPending.value || settings.isPending.value || (settingsReady.value && rates.isPending.value),
    ),
    isError: computed(() => accounts.isError.value || settings.isError.value || rates.isError.value),
    refetch: () => Promise.all([accounts.refetch(), settings.refetch(), rates.refetch()]),
  }
}
```

```ts
  name: string
  type: AccountType

  openingBalance: number | null
  cardLast4: string

type Translate = (key: string) => string

export const isCardLast4 = (value: unknown): boolean =>

    currency: { required: requiredField },
```

```ts
import { helpers, maxLength, minValue, required, requiredIf } from '@vuelidate/validators'

export const TRANSFER_NOTE_MAX = 200

export type TransferForm = {
  fromAccountId: string | null
  toAccountId: string | null
  amount: number | null
  date: Date | null
  rate: number | null
  note: string
}

type Translate = (key: string) => string

export const differentFrom =
  (other: () => string | null) =>
  (value: unknown): boolean =>
    value === null || value === undefined || value !== other()

export const isPositiveOrEmpty = (value: unknown): boolean =>
  value === null || value === undefined || (typeof value === 'number' && value > 0)

export const transferRules = (t: Translate, form: TransferForm, crossCurrency: () => boolean) => {
  const requiredField = helpers.withMessage(() => t('validation.required'), required)
  return {
    fromAccountId: { required: requiredField },
    toAccountId: {
      required: requiredField,
      different: helpers.withMessage(() => t('validation.sameAccount'), differentFrom(() => form.fromAccountId)),
    },
    amount: {
      required: requiredField,
      positive: helpers.withMessage(() => t('validation.positiveAmount'), minValue(0.01)),
    },
    date: { required: requiredField },
    rate: {
      required: helpers.withMessage(() => t('validation.required'), requiredIf(crossCurrency)),
      positive: helpers.withMessage(() => t('validation.positiveAmount'), isPositiveOrEmpty),
    },
    note: { maxLength: helpers.withMessage(() => t('validation.noteTooLong'), maxLength(TRANSFER_NOTE_MAX)) },
  }
}
```

```vue
const crossCurrency = computed(
  () => !!fromAccount.value && !!toAccount.value && fromAccount.value.currency !== toAccount.value.currency,
)
const v$ = useVuelidate(
  transferRules(t, form, () => crossCurrency.value),
  form,
)

const rateDate = computed(() => (form.date ? fromLocalDate(form.date) : todayIso()))
const rates = useRates(() => toAccount.value?.currency ?? 'PLN', { date: rateDate, enabled: crossCurrency })
const suggestedRate = computed(() =>
  fromAccount.value && crossCurrency.value ? rates.rateFrom(fromAccount.value.currency) : undefined,
)

watch(suggestedRate, (rate) => {
  if (rate !== undefined && !rateEdited.value) form.rate = rate
})

watch(
  () => [fromAccount.value?.currency, toAccount.value?.currency],
  () => {
    rateEdited.value = false
    form.rate = suggestedRate.value ?? null
  },
)

const accountOptions = computed(() =>
  activeAccounts.value.map((account) => ({ value: account.id, label: `${account.name} · ${account.currency}` })),
)
const maxDate = computed(() => toLocalDate(addDaysIso(todayIso(), 365)))
const receives = computed(() => {
  if (!toAccount.value || form.amount === null || form.amount <= 0) return undefined
  const rate = crossCurrency.value ? form.rate : 1
  if (rate === null || rate <= 0) return undefined
  return t('accounts.transferDialog.receives', {
    amount: format(convertMinor(toMinor(form.amount), rate), toAccount.value.currency),
  })
})

function reset() {
  const [first, second] = activeAccounts.value
  Object.assign(form, {
    fromAccountId: first?.id ?? null,
    toAccountId: second?.id ?? null,
    amount: null,
    date: toLocalDate(todayIso()),
    note: '',
  })
  rateEdited.value = false
  form.rate = suggestedRate.value ?? null
  server.clear()
  v$.value.$reset()
}

watch(visible, (open) => {
  if (open) reset()
})

const errorsOf = (field: Field) => [
  ...v$.value[field].$errors.map((error) => String(unref(error.$message))),
  ...server.messages(field),
]

function touch(field: Field) {
  v$.value[field].$touch()
  server.clear(field)
}

function onRateInput() {
  rateEdited.value = true
}

async function submit() {
  server.clear()
  if (!(await v$.value.$validate())) {
    await nextTick()
    focusFirstInvalid(formEl.value)
    return
  }
  const note = form.note.trim()
  const input: TransferInput = {
    date: fromLocalDate(form.date as Date),
    fromAccountId: form.fromAccountId as string,
    toAccountId: form.toAccountId as string,
    fromAmount: toMinor(form.amount ?? 0),
    ...(crossCurrency.value && form.rate !== null ? { rate: form.rate } : {}),
    ...(note ? { note } : {}),
  }
  createTransfer.mutate(input, {
    onSuccess: () => {
      notify.success(t('accounts.toast.transferCreated'))
      visible.value = false
    },
    onError: async (error) => {
      if (server.apply(error, fields, { fromAmount: 'amount' })) {
        await nextTick()
        focusFirstInvalid(formEl.value)
      } else notify.error(error)
    },
  })
}
</script>
```
