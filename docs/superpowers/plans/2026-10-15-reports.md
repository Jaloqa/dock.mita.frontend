# Reports Implementation Plan

**Goal:** Deliver the reports screen end to end: a mock aggregate `GET /v1/reports?range=3m|6m|12m` in the base currency (income and expenses per financial period, range totals, average income and expense per period, savings rate, the spending structure of the current financial period) and the `/reports` screen per `Reports` (header with the range control and "Export PDF", three stat cards, grouped income/expense bar chart with PrimeVue `Chart`, spending structure with plain HTML bars) and `Mobile-Reports` below `lg` (range label in the header, icon export button, range control, two stat cards, compact chart, structure list), with loading, error and empty states and a print stylesheet that turns `window.print()` into an A4 PDF in light colours.

**Architecture:** The mock backend gains `mocks/reports.ts` (`savingsRateOf`, `structureOf`, `reportOf`) and `mocks/handlers/reports.ts`, and `mocks/overview.ts` gains `lastPeriods` next to `rangesOf`. It reuses `transactionsIn`, `baseAmountOf`, `baseCurrencyOf`, `spentByCategory`, `monthStartOf`, `ownCategories` and `shareTenths` instead of new sums. On the frontend a new `app/features/reports` owns the API module, query keys, composables (aggregate query, URL range, range label, percent formatting), pure view helpers and the section components, all rendered from the aggregate DTO; it does not import `features/overview`. `app/pages/reports.vue` composes the feature. Print support is CSS (`print:` utilities, `@page`, screen-only dark tokens) plus a `beforeprint`/`afterprint` repaint of the canvas.

**Tech Stack:** Nuxt 4, TypeScript strict, TanStack Query (`useQuery` with `keepPreviousData`), PrimeVue 4 (`Chart` with Chart.js 4.5.1, `SelectButton`, `Button`, `Skeleton`), vue-i18n, Tailwind 4 (`print:` variant), Bun (`bun test`), Playwright, Biome.

**Spec:** `docs/superpowers/specs/2026-10-15-frontend-mocks-design.md` (section 1 rules on financial periods, transfers and currency; section 2 aggregates, endpoints and invalidation; section 3 Reports screen and the PDF-through-print decision; section 4 loading/error/empty behaviour; section 5 step 8).

## Global Constraints

- Code, identifiers, commit messages in English; no comments except for a genuinely controversial decision; no tool attribution, no `Co-Authored-By` trailers, no mention of assistants anywhere (commits, PR, code, committed files).
- Conventional Commits; one commit per task with the message given in the task.
- API paths start with `/v1/`; errors are RFC 9457 ProblemDetails; validation messages are i18n keys under `validation.*`. The frontend never sends `userId`; every handler filters by the session user.
- `GET /v1/reports?range=` accepts `3m | 6m | 12m` (default `6m`); anything else is `400 { range: ['validation.invalidValue'] }`. A range is the last N financial periods (N = 3 / 6 / 12, `reportRangePeriods`) ending with the current one (`periodFor(today, monthStartDay)`), oldest first.
- All amounts are minor units in the user's base currency (`baseAmountOf`); `currency` in the DTO is the base currency. Transactions whose category is the `transfer` system category are excluded from every figure; transfers are never income or expense.
- `averageIncome` / `averageExpense` = range total ÷ N, rounded to a minor unit (the current, partial period counts). `savingsRate` = (income − expense) ÷ income × 100 over the range totals, one decimal, rounded half away from zero, may be negative, `null` when income is 0.
- Structure = the current financial period's expenses by category (`spentByCategory`), transfer category excluded, the system `other` category a normal row, every category with an amount above 0, sorted by amount desc then name; `percent` one decimal via `shareTenths` (sums to exactly 100.0); `total` = sum of the rows.
- Invalidation: `settings`, `accounts`, `categories`, `transactions` and `demo` (everything) refresh `['reports']`; `transfers`, `budgets`, `goals` and `goalContributions` do not (already so in the map; Task 2 pins it). Query keys `['reports', range]`.
- The range lives in the URL as `?range=3m|6m|12m`, validated with fallback to `6m`, changed with `router.replace`.
- Consumers of `useUserSettings` must not format money with the PLN fallback while settings are pending or errored. Not applicable here: the page does not consume `useUserSettings`; the currency comes from the DTO.
- The UI never shows `ApiError.title` raw: the screen's only error is the shared `ErrorState` with i18n copy.
- Data queries run on the client only in mock mode — no `suspense()`, no server prefetch. The chart renders inside `<ClientOnly>`.
- Every user-facing string goes through i18n with keys in `en`, `pl`, `ru`, `uk` under `reports.*` (the parity test enforces it); keys are camelCase; dates through `d()` (`useMonthLabel`), numbers and percentages through `n()`, money through `useMoney().format` / `MoneyText`; plural keys give 2 forms in `en` and 3 in `pl`, `ru`, `uk`.
- Accessibility: semantic elements, sections named by their heading or `aria-label`, touch targets at least 44px (links `inline-flex min-h-11 items-center`, the icon export button `size-11`), duplicated desktop/mobile blocks hidden with `display: none` so only one is exposed. The chart canvas has `role="img"` and an `aria-label` with the range and totals; a visually hidden table lists every period; the visible legend is `aria-hidden`; structure bars are `aria-hidden` (name, amount and share are text).
- Design tokens only, never hex values in components; chart colours are read from `--mita-chart-income`, `--mita-chart-expense`, `--mita-border`, `--mita-muted` at runtime and re-read when the `<html>` class changes; the print palette is read from the `--mita-light-*` source tokens. Amounts and percentages use `font-mono`. Radius: 10px controls, 16px cards.
- Features must not import other features' internals: `features/reports` does not import `features/overview` (the palette observer and percent formatting are duplicated on purpose). Only libraries from `docs/STACK.md`; PrimeVue stays on 4.x; no new dependency (Chart.js 4.5.1 is already installed).
- Code under `mocks/`, `app/shared/api/{contract,invalidation}.ts`, `app/shared/period` and `app/features/reports/utils` uses plain relative imports (no Nuxt auto-imports, no `~` alias) so it runs in Bun.
- Biome (`bun run lint`) and `nuxt typecheck` (0 `error TS` lines) must pass before every commit.
- Commands run inside WSL through `wsl.exe -d Debian -- bash /home/jaloqa/dock.mita-work/wsl-run.sh '<cmd>'`; E2E through `wsl.exe -d Debian -- bash /home/jaloqa/dock.mita-work/scripts/reports-e2e.sh [spec files] [playwright args]` (created in Task 3; dev server on port 3100, Playwright container, both projects).

## Review Focus

- The base currency changed after data exists: every period, total and structure row is re-priced at each transaction's date and the DTO currency follows the setting. Pinned in Task 1.

- A failed load, a brand-new user and a range without any income or expense: one error with retry, "No reports yet", "No data for this range" with "Show the year", export disabled. Pinned in Task 3 and Task 6.
- An unknown `?range=` in the URL or an invalid `range` sent to the API: the screen falls back to six months, the API answers 400. Pinned in Task 1 (unit) and Task 3 (E2E).
- A transaction saved anywhere — the sidebar dialog on desktop, the keypad screen on mobile — refreshes the report without a reload. Pinned in Task 7.
- Switching the theme while the chart is on screen: colours are re-read and the chart re-renders. Pinned in Task 4.

## Decisions taken for this stage

- **Feature placement:** a new `app/features/reports` (API, keys, composables, view helpers, components) renders everything from the aggregate DTO. It does not import `features/overview`; the chart palette observer and the percent formatter are duplicated (ruling: the `shared/` threshold is three features; cost if wrong: one small extraction later).
- **Ranges:** `3m | 6m | 12m` = the last 3 / 6 / 12 financial periods ending with the current one, default `6m`; `reportRangePeriods` in the contract is the single source of N for the mock and the UI. The helper `lastPeriods(today, monthStart, count)` lives in `mocks/overview.ts` next to `rangesOf`.
- **Averages:** range total ÷ N, the current partial period included (ruling: dividing by N, not by periods with data; cost if wrong: one divisor). An empty range gives `0`, not `null` (the empty state hides the cards anyway).
- **Savings rate:** (income − expense) ÷ income × 100 over range totals, one decimal, rounded half away from zero, negative allowed, `null` without income (UI "—"). The UI shows it as a whole percent ("33%") like the design. `percentChange` rounds with `Math.round` (half up), so the two differ only on exact negative halves (ruling; cost if wrong: one rounding call).
- **Structure:** current financial period only, all categories with spending (the design's mobile shows five; ruling: both layouts show all; cost if wrong: a `slice`), `other` is a normal row, sorted by amount desc then name, one-decimal shares via `shareTenths`. Bars are plain HTML in `accent` on a `bg` track, width = amount ÷ largest amount. Desktop title "Spending structure · October" with the total on the right; mobile "Spending · October" with name, share and a thin bar.
- **Header:** desktop eyebrow "Analytics", `h1` "Reports", actions: range `SelectButton` ("3 months", "6 months", "Year"; the month labels are a plural key) and an outlined "Export PDF" button with the existing `download` icon. Mobile eyebrow = the range label ("May – October 2026", start year only when the years differ, built from period keys with `useMonthLabel`), `h1` "Reports", a 44px icon-only export button (native `button`, PrimeVue's icon-only `Button` expects a PrimeIcons class) named "Export PDF".
- **Mobile range control:** the `SelectButton` is also shown on mobile under the header (ruling: the design has none, without it mobile cannot switch; cost if wrong: one element).
- **Cards:** desktop three `StatCard`s (average income, average expense, savings rate in `accent`); mobile two compact cards (average expense, "Savings").
- **Chart:** PrimeVue `Chart` `type="bar"`, grouped income/expense per period, short month names on x, compact money on y (`notation: 'compact'`), tooltip with the formatted amount, Chart.js legend off, visible HTML legend `aria-hidden`, canvas `role="img"` + `aria-label` ("Income and expenses, May – October 2026: total income …, total expenses …"), a `sr-only` table (month, income, expenses), animation off under `prefers-reduced-motion`, inside `<ClientOnly>`. Data in minor units. Desktop 220px high, mobile 130px with 11px ticks, "By month" and short legends.
- **Chart tokens:** `--mita-chart-income` = `accent`; `--mita-chart-expense` = `deep` in light and `ink` in dark (`deep` is near-invisible on the dark surface); grid lines `border`, ticks `muted`; mapped into Tailwind as `bg-chart-income` / `bg-chart-expense`. Every light hex lives once in `--mita-light-*` source tokens that `:root` references, so the print palette has no duplicated hex.
- **Errors and loading:** one query; skeletons for the cards, the chart and the structure while it loads; a failed load without cached data (`isError && !report`) shows one `ErrorState` with retry replacing the content while the header stays usable; with cached data a failed refetch keeps showing the data.
- **Empty states:** `hasTransactions === false` → `EmptyState` "No reports yet" with the link "Add a transaction" (`/transactions`); a range with no income and no expense → "No data for this range" ("Nothing was recorded in {range}.") with "Show the year" when the range is not `12m`; current period without expenses while the range has data → "No expenses in {month}." inside the structure card.
- **Export:** "Export PDF" calls `window.print()`. Disabled while loading, while the previous range is shown as placeholder data (ruling added: printing the old range under a new selection would mislead; cost: one condition), when the load failed, and in both empty states.
- **Print (each a ruling):** A4 portrait via `@page { size: A4; margin: 12mm }`; the sidebar, the bottom navigation, both range controls and both export buttons get `print:hidden`; the desktop layout is printed whatever the paper width (`hidden lg:flex print:flex!` / `lg:hidden print:hidden!`); cards `break-inside-avoid` and, in print only, a 1px `border` on a `surface` page background (page and card would otherwise both be white); a print-only line "Period covered: May – October 2026" under the header; the `.dark` token block is wrapped in `@media screen` so print always uses light tokens, with `print-color-adjust: exact` so bar backgrounds print; the canvas is drawn by JS, so the desktop chart listens to `beforeprint`, assigns data and options built from the `--mita-light-*` palette to the Chart.js instance (`getChart()`), resizes it to 640×220 (the print width of its wrapper, `print:w-160`) and calls `update('none')` synchronously, and restores the screen palette and size on `afterprint`; the compact chart never prints and does not listen. PrimeVue's own tokens under `.dark` are not forced light, because every PrimeVue control on the page is hidden in print.
- **Failure and empty states in E2E:** the same techniques as the overview: persist the mock DB with one save (the sidebar dialog on desktop, the keypad on mobile), set `simulateErrors: true` in `localStorage['mita-mock-db-v1']` and pin `Math.random` with `addInitScript`; the brand-new user is the active demo user with accounts, transactions, transfers, budgets, goals and contributions removed; the empty range keeps one of the user's transactions older than 120 days. `emulateMedia({ media: 'print' })` does not fire `beforeprint`, so the canvas repaint is pinned by dispatching the event. Recorded gap: the loading skeletons and the disabled export while loading are not pinned by E2E (timing-dependent with the mock delay of 150–400 ms).
- **Translations up front:** all `reports.*` keys are added in Task 2 (with the composables) instead of with the page, so every later task has its strings (ruling; cost: none).
- **Settings gating:** the page does not consume `useUserSettings`; the DTO carries the base currency.
- **No new tables:** the aggregate is computed on read; `MockState` and the seed are unchanged.

```ts
import { describe, expect, it } from 'bun:test'
import type { ReportDto } from '../../../app/shared/api/contract'
import { convertMinor } from '../../../app/shared/money/money'
import { addDaysIso, periodFor, shiftPeriod, todayIso } from '../../../app/shared/period/period'
import { createMockApi, type MockApi } from '../../../mocks/api'
import { defaultHandlers } from '../../../mocks/handlers'
import { lastPeriods } from '../../../mocks/overview'
import { rateOn } from '../../../mocks/rates'
import { savingsRateOf } from '../../../mocks/reports'

const today = todayIso()
const current = periodFor(today, 1)
const back = (months: number) => shiftPeriod(current.key, -months, 1)
const expenseCategory = (key: string) => `cat_anna_expense_${key}`
const salary = 'cat_anna_income_salary'

const failure = (promise: Promise<unknown>) => promise.catch((error: unknown) => error)

const api = (): MockApi => {
  const mock = createMockApi({ register: defaultHandlers })
  Object.assign(mock.db.state, { transactions: [], transfers: [], budgets: [], goals: [], goalContributions: [] })
  return mock
}

const report = (mock: MockApi, range?: string) =>
  mock.handle({
    method: 'GET',
    path: '/v1/reports',
    query: range === undefined ? undefined : { range },
  }) as Promise<ReportDto>

const record = (
  mock: MockApi,
  kind: 'expense' | 'income',
  categoryId: string,
  amount: number,
  date = today,
  extra: Record<string, unknown> = {},
) =>
  mock.handle({
    method: 'POST',
    path: '/v1/transactions',
    body: { kind, date, categoryId, accountId: 'acc_anna_card', amount, currency: 'PLN', ...extra },
  })

describe('report rules', () => {
  it('lists the financial periods ending with the current one, oldest first', () => {
    expect(lastPeriods('2026-10-16', 1, 3)).toEqual([
      { key: '2026-08', from: '2026-08-01', to: '2026-08-31' },
      { key: '2026-09', from: '2026-09-01', to: '2026-09-30' },
      { key: '2026-10', from: '2026-10-01', to: '2026-10-31' },
    ])
    expect(lastPeriods('2026-10-16', 10, 3)).toEqual([
      { key: '2026-08', from: '2026-08-10', to: '2026-09-09' },
      { key: '2026-09', from: '2026-09-10', to: '2026-10-09' },
      { key: '2026-10', from: '2026-10-10', to: '2026-11-09' },
    ])
    expect(lastPeriods('2026-10-05', 10, 3).map((row) => row.key)).toEqual(['2026-07', '2026-08', '2026-09'])
    expect(lastPeriods('2026-02-10', 1, 12).map((row) => row.key)).toEqual([
      '2025-03',
      '2025-04',
      '2025-05',
      '2025-06',
      '2025-07',
      '2025-08',
      '2025-09',
      '2025-10',
      '2025-11',
      '2025-12',
      '2026-01',
      '2026-02',
    ])
  })

  it('computes the savings rate with one decimal, rounded half away from zero', () => {
    expect(savingsRateOf(300_000, 200_000)).toBe(33.3)
    expect(savingsRateOf(1_000, 0)).toBe(100)
    expect(savingsRateOf(100_000, 150_000)).toBe(-50)
    expect(savingsRateOf(2_000, 1_999)).toBe(0.1)
    expect(savingsRateOf(2_000, 2_001)).toBe(-0.1)
    expect(savingsRateOf(2_000, 2_000)).toBe(0)
    expect(savingsRateOf(100_000, 100_004)).toBe(0)
    expect(savingsRateOf(0, 5_000)).toBeNull()
    expect(savingsRateOf(0, 0)).toBeNull()
  })
})

describe('report', () => {
  it('sums income and expenses per financial period over six months by default', async () => {
    const mock = api()
    await record(mock, 'income', salary, 700_000, current.from)
    await record(mock, 'expense', expenseCategory('housing'), 80_000, today)
    await record(mock, 'income', salary, 500_000, back(5).from)
    await record(mock, 'expense', expenseCategory('groceries'), 40_000, back(5).to)
    await record(mock, 'expense', expenseCategory('groceries'), 10_001, back(2).from)
    await record(mock, 'expense', expenseCategory('groceries'), 99_999, back(6).to)
    const result = await report(mock)
    expect(result).toMatchObject({ range: '6m', from: back(5).from, to: current.to, currency: 'PLN' })
    expect(result.periods.map((row) => row.period)).toEqual([5, 4, 3, 2, 1, 0].map((months) => back(months).key))
    expect(result.periods[0]).toEqual({
      period: back(5).key,
      from: back(5).from,
      to: back(5).to,
      income: 500_000,
      expense: 40_000,
    })
    expect(result.periods[3]).toMatchObject({ period: back(2).key, income: 0, expense: 10_001 })
    expect(result.periods[5]).toMatchObject({ period: current.key, income: 700_000, expense: 80_000 })
    expect(result).toMatchObject({
      totals: { income: 1_200_000, expense: 130_001 },
      averageIncome: 200_000,
      averageExpense: 21_667,
      savingsRate: 89.2,
      hasTransactions: true,
    })
  })

  it('covers three and twelve financial periods', async () => {
    const mock = api()
    await record(mock, 'expense', expenseCategory('groceries'), 1_000, back(2).from)
    await record(mock, 'expense', expenseCategory('groceries'), 2_000, back(3).to)
    await record(mock, 'expense', expenseCategory('groceries'), 4_000, back(11).from)
    await record(mock, 'expense', expenseCategory('groceries'), 8_000, back(12).to)
    const quarter = await report(mock, '3m')
    expect(quarter).toMatchObject({
      range: '3m',
      from: back(2).from,
      to: current.to,
      totals: { income: 0, expense: 1_000 },
      averageIncome: 0,
      averageExpense: 333,
      savingsRate: null,
    })
    expect(quarter.periods).toHaveLength(3)
    const year = await report(mock, '12m')
    expect(year).toMatchObject({ range: '12m', from: back(11).from, totals: { expense: 7_000 }, averageExpense: 583 })
    expect(year.periods).toHaveLength(12)
  })

  it('follows the financial month of the session user and never mixes users', async () => {
    const mock = api()
    await record(mock, 'expense', expenseCategory('groceries'), 5_000)
    mock.db.state.activeUserId = 'usr_oleh'
    const period = periodFor(today, 10)
    const olehCard = { accountId: 'acc_oleh_card', currency: 'UAH' }
    await record(mock, 'expense', 'cat_oleh_expense_groceries', 30_000, period.from, olehCard)
    await record(mock, 'expense', 'cat_oleh_expense_groceries', 20_000, addDaysIso(period.from, -1), olehCard)
    const result = await report(mock)
    expect(result.currency).toBe('UAH')
    expect(result.periods.at(-1)).toEqual({
      period: period.key,
      from: period.from,
      to: period.to,
      income: 0,
      expense: 30_000,
    })
    expect(result.periods.at(-2)).toMatchObject({ to: addDaysIso(period.from, -1), expense: 20_000 })
    expect(result.totals).toEqual({ income: 0, expense: 50_000 })
    expect(result.structure).toMatchObject({ period: period.key, total: 30_000 })
  })

  it('re-prices every amount when the base currency changes', async () => {
    const mock = api()
    await record(mock, 'expense', expenseCategory('groceries'), 10_000)
    await record(mock, 'income', salary, 50_000)
    const settings = mock.db.state.settings.find((row) => row.userId === 'usr_anna')
    if (!settings) throw new Error('Anna has no settings')
    settings.baseCurrency = 'EUR'
    const inEur = (amount: number) => convertMinor(amount, rateOn(mock.db.state.rates, today, 'PLN', 'EUR'))
    const result = await report(mock)
    expect(result.currency).toBe('EUR')
    expect(result.periods.at(-1)).toMatchObject({ income: inEur(50_000), expense: inEur(10_000) })
    expect(result.totals).toEqual({ income: inEur(50_000), expense: inEur(10_000) })
    expect(result.structure.items[0]?.amount).toBe(inEur(10_000))
  })

  it('leaves transfers out of every figure', async () => {
    const mock = api()
    await record(mock, 'expense', expenseCategory('groceries'), 10_000)
    const sample = mock.db.state.transactions[0]
    if (!sample) throw new Error('no transaction recorded')
    mock.db.state.transactions.push({
      ...sample,
      id: 'txn_transfer_category',
      categoryId: expenseCategory('transfer'),
      amount: 99_000,
      accountAmount: 99_000,
      baseAmount: 99_000,
    })
    await mock.handle({
```

```ts
import {
  type CategoryColor,
  type ReportDto,
  type ReportPeriodDto,
  type ReportRange,
  type ReportStructureDto,
  reportRangePeriods,
} from '../app/shared/api/contract'
import type { Currency } from '../app/shared/money/money'
import { type Period, periodFor } from '../app/shared/period/period'
import { monthStartOf, spentByCategory } from './budgets'
import { ownCategories } from './categories'
import type { CategoryRow, MockDb, MockState, TransactionRow } from './db'
import { lastPeriods, shareTenths } from './overview'
import { baseAmountOf, baseCurrencyOf, transactionsIn } from './transactions'

type Categories = ReadonlyMap<string, Pick<CategoryRow, 'name' | 'color' | 'system'>>

export function savingsRateOf(income: number, expense: number): number | null {
  if (income <= 0) return null
  const tenths = ((income - expense) * 1000) / income
  const rounded = Math.round(Math.abs(tenths))
  return rounded === 0 ? 0 : (Math.sign(tenths) * rounded) / 10
}

function periodTotals(
  state: MockState,
  rows: readonly TransactionRow[],
  base: Currency,
  period: Period,
): ReportPeriodDto {
  let income = 0
  let expense = 0
  for (const row of rows) {
    if (row.date < period.from || row.date > period.to) continue
    const amount = baseAmountOf(state, row, base)
    if (row.kind === 'income') income += amount
    else expense += amount
  }
  return { period: period.key, from: period.from, to: period.to, income, expense }
}

export function structureOf(
  spent: ReadonlyMap<string, number>,
  categories: Categories,
  period: Period,
): ReportStructureDto {
  const entries: { categoryId: string; name: string; color: CategoryColor; amount: number }[] = []
  for (const [categoryId, amount] of spent) {
    const category = categories.get(categoryId)
    if (!category || amount <= 0 || category.system === 'transfer') continue
    entries.push({ categoryId, name: category.name, color: category.color, amount })
  }
  entries.sort((a, b) => b.amount - a.amount || a.name.localeCompare(b.name))
  const tenths = shareTenths(entries.map((entry) => entry.amount))
  return {
    period: period.key,
    from: period.from,
    to: period.to,
    total: entries.reduce((sum, entry) => sum + entry.amount, 0),
    items: entries.map((entry, index) => ({ ...entry, percent: (tenths[index] ?? 0) / 10 })),
  }
}

export function reportOf(db: MockDb, userId: string, range: ReportRange, today: string): ReportDto {
  const { state } = db
  const base = baseCurrencyOf(state, userId)
  const monthStart = monthStartOf(state, userId)
  const categories: Categories = new Map(ownCategories(db, userId).map((row) => [row.id, row]))
  const current = periodFor(today, monthStart)
  const periods = lastPeriods(today, monthStart, reportRangePeriods[range])
  const from = periods[0]?.from ?? current.from
  const rows = transactionsIn(state, userId, { from, to: current.to }).filter(
    (row) => categories.get(row.categoryId)?.system !== 'transfer',
  )
  const byPeriod = periods.map((period) => periodTotals(state, rows, base, period))
  const totals = byPeriod.reduce(
    (sum, row) => ({ income: sum.income + row.income, expense: sum.expense + row.expense }),
    { income: 0, expense: 0 },
  )
  const count = Math.max(byPeriod.length, 1)

  return {
    range,
    from,
    to: current.to,
    currency: base,
    periods: byPeriod,
    totals,
    averageIncome: Math.round(totals.income / count),
    averageExpense: Math.round(totals.expense / count),
    savingsRate: savingsRateOf(totals.income, totals.expense),
    structure: structureOf(spentByCategory(state, userId, base, current), categories, current),
    hasTransactions: state.transactions.some((row) => row.userId === userId),
  }
}
```

```ts
import { isReportRange, type ReportDto, type ReportRange } from '../../../shared/api/contract'

type ReportFacts = Pick<ReportDto, 'hasTransactions' | 'totals'>

export type ReportState = 'noTransactions' | 'noData' | 'ready'

export const resolveReportRange = (value: unknown): ReportRange => (isReportRange(value) ? value : '6m')

export const sameYear = (fromKey: string, toKey: string): boolean => fromKey.slice(0, 4) === toKey.slice(0, 4)

export function rangeEnds(periods: readonly { period: string }[]): { first: string; last: string } | null {
  const first = periods[0]?.period
  const last = periods[periods.length - 1]?.period
  return first !== undefined && last !== undefined ? { first, last } : null
}

export function reportStateOf(report: ReportFacts): ReportState {
  if (!report.hasTransactions) return 'noTransactions'
  return report.totals.income > 0 || report.totals.expense > 0 ? 'ready' : 'noData'
}

export const canExport = (report: ReportFacts | undefined, stale: boolean): boolean =>
  !stale && report !== undefined && reportStateOf(report) === 'ready'

export const largestOf = (items: readonly { amount: number }[]): number =>
  items.reduce((largest, item) => Math.max(largest, item.amount), 0)

export const barShare = (amount: number, largest: number): number => (largest > 0 ? Math.min(amount / largest, 1) : 0)
```

```ts
const table = (page: Page) => page.getByRole('table', { name: 'Income and expenses by month' })

const tokenPixel = (page: Page, token: string) =>
  page.evaluate((name) => {
    const context = document.createElement('canvas').getContext('2d')
    if (!context) return []
    context.fillStyle = getComputedStyle(document.documentElement).getPropertyValue(name).trim()
    context.fillRect(0, 0, 1, 1)
    return Array.from(context.getImageData(0, 0, 1, 1).data)
  }, `--mita-${token}`)

const colorPixels = (canvas: Locator, rgba: number[]) =>
  canvas.evaluate((element: HTMLCanvasElement, target) => {
    const context = element.getContext('2d')
    if (!context || element.width === 0 || element.height === 0) return 0
    const { data } = context.getImageData(0, 0, element.width, element.height)
    let count = 0
    for (let index = 0; index < data.length; index += 4) {
      if (
        data[index] === target[0] &&
        data[index + 1] === target[1] &&
        data[index + 2] === target[2] &&
        data[index + 3] === 255
      ) {
        count += 1
      }
    }
    return count
  }, rgba)
```

```vue
<script setup lang="ts">
import type { ChartData, ChartOptions, TooltipItem } from 'chart.js'
import type { ReportPeriodDto } from '~/shared/api/contract'
import { type Currency, fromMinor } from '~/shared/money/money'
import { monthKeyDate } from '~/shared/period/period'

type Palette = { income: string; expense: string; grid: string; tick: string }

const props = defineProps<{
  periods: ReportPeriodDto[]
  currency: Currency
  description: string
  compact?: boolean
}>()
const { t, d, n } = useI18n()
const { format } = useMoney()
const monthLabel = useMonthLabel()

const reducedMotion = ref(false)
const palette = ref<Palette>()
let observer: MutationObserver | undefined

function readPalette(prefix: '' | 'light-'): Palette {
  const style = getComputedStyle(document.documentElement)
  const token = (name: string) => style.getPropertyValue(`--mita-${prefix}${name}`).trim()
  return { income: token('chart-income'), expense: token('chart-expense'), grid: token('border'), tick: token('muted') }
}

const shortMonth = (key: string) => d(monthKeyDate(key), { month: 'short', timeZone: 'UTC' })
const compactMoney = (minor: number) =>
  n(fromMinor(minor), { key: 'currency', currency: props.currency, notation: 'compact', maximumFractionDigits: 1 })

function dataFor(colors: Palette): ChartData<'bar', number[], string> {
  const bar = { borderRadius: props.compact ? 4 : 5, maxBarThickness: props.compact ? 14 : 22 }
  return {
    labels: props.periods.map((row) => shortMonth(row.period)),
    datasets: [
      {
        label: t('reports.chart.income'),
        data: props.periods.map((row) => row.income),
        backgroundColor: colors.income,
        ...bar,
      },
      {
        label: t('reports.chart.expense'),
        data: props.periods.map((row) => row.expense),
        backgroundColor: colors.expense,
        ...bar,
      },
    ],
  }
}

function optionsFor(colors: Palette): ChartOptions<'bar'> {
  return {
    responsive: true,
    maintainAspectRatio: false,
    animation: reducedMotion.value ? false : undefined,
    plugins: {
      legend: { display: false },
      tooltip: {
        callbacks: {
          label: (item: TooltipItem<'bar'>) => `${item.dataset.label ?? ''}: ${format(item.parsed.y, props.currency)}`,
        },
      },
    },
    scales: {
      x: {
        grid: { display: false },
        border: { color: colors.grid },
        ticks: { color: colors.tick, font: { size: props.compact ? 11 : 12 } },
      },
      y: {
        beginAtZero: true,
        border: { display: false },
        grid: { color: colors.grid },
        ticks: {
          color: colors.tick,
          maxTicksLimit: props.compact ? 4 : 5,
          callback: (value) => compactMoney(Number(value)),
        },
      },
    },
  }
}

const data = computed(() => (palette.value ? dataFor(palette.value) : undefined))
const options = computed(() => (palette.value ? optionsFor(palette.value) : undefined))

onMounted(() => {
  reducedMotion.value = window.matchMedia('(prefers-reduced-motion: reduce)').matches
  palette.value = readPalette('')
  observer = new MutationObserver(() => {
    palette.value = readPalette('')
  })
  observer.observe(document.documentElement, { attributes: true, attributeFilter: ['class'] })
})

onBeforeUnmount(() => observer?.disconnect())
</script>

<template>
  <div class="flex flex-col">
    <div class="relative w-full" :class="compact ? 'h-32.5' : 'h-55'">
      <ClientOnly>
        <Chart
          v-if="data && options"
          type="bar"
          class="size-full"
          :data="data"
          :options="options"
          :canvas-props="{ role: 'img', 'aria-label': description }"
        />
      </ClientOnly>
    </div>
    <table class="sr-only">
      <caption>{{ t('reports.chart.title') }}</caption>
      <thead>
        <tr>
          <th scope="col">{{ t('reports.chart.month') }}</th>
          <th scope="col">{{ t('reports.chart.income') }}</th>
          <th scope="col">{{ t('reports.chart.expense') }}</th>
        </tr>
      </thead>

          <td>{{ format(row.expense, currency) }}</td>
        </tr>
      </tbody>
```
