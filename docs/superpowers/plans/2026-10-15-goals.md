# Goals Implementation Plan

**Goal:** Deliver goals end to end: the mock backend (`Goal` per user with target, saved, optional deadline month and optional linked savings account; `GoalContribution`; percent, remaining, status and "save X per month" hint; a summary with the saved total, the average monthly saving and the number of active goals; contributions to a linked goal recorded as real transfers into its savings account; validation; `linkedGoals` on accounts; seeded goals and contribution history for both demo users) and the `/goals` screen (summary cards, goal cards with progress and hints, reached and overdue states, new/edit/delete goal dialog, contribution dialog with a transfer preview and an exchange rate for cross-currency contributions, compact mobile layout, loading/empty/error states) plus the "Linked to goals" meta line on the accounts screen.

**Architecture:** The mock backend gains `goals` and `goalContributions` tables, pure goal rules in `mocks/goals.ts` (months to the deadline, status, monthly hint, re-pricing into the base currency, list view, summary, linked-goal counts, unlinking) and handlers for `/v1/goals`. The transfer creation logic moves from `mocks/handlers/transfers.ts` into `mocks/transfers.ts` (`checkAccount`, `transferRow`) so `POST /v1/transfers` and `POST /v1/goals/{id}/contributions` build identical transfer rows. Goal rows keep the base currency their amounts are stored in; reads convert them at today's rate, and every write (PUT or contribution) re-bases the row into the current base currency. On the frontend `app/features/goals` owns the API module, query keys, composables (list, mutations), pure view helpers, Vuelidate rules and components; `app/pages/goals.vue` composes them with the shared accounts list. A shared `useMonthLabel` replaces the three copies of the month-label code.

**Tech Stack:** Nuxt 4, TypeScript strict, TanStack Query (`useQuery`, `useMutation`), Vuelidate, PrimeVue 4 (`Dialog`, `Select`, `InputNumber`, `InputText`, `DatePicker` with `view="month"`, `Skeleton`, `Toast`, `ConfirmDialog`), vue-i18n, Tailwind 4, Bun (`bun test`), Playwright, Biome.

**Spec:** `docs/superpowers/specs/2026-10-15-frontend-mocks-design.md` (section 1 `Goal`, `GoalContribution` and the goal rules, section 2 endpoints and invalidation, section 3 Goals screen, section 4 forms and errors, section 5 step 6).

## Global Constraints

- Code, identifiers, commit messages in English; no comments except for a genuinely controversial decision; no tool attribution and no `Co-Authored-By` trailers in commits or files.
- API paths start with `/v1/`; errors are RFC 9457 ProblemDetails; validation messages are i18n keys under `validation.*`.
- The frontend never sends `userId`; every handler filters by the session user; a foreign or missing goal id returns `404`.
- Goal row = `{ id, userId, name, target, saved, currency, deadline: string | null ('YYYY-MM'), accountId: string | null, createdAt }`; `currency` is the base currency `target` and `saved` are stored in. Reads convert a row whose `currency` differs from the user's base currency at today's rate (`rateOn`); every PUT and every contribution first re-bases the row (target and saved converted at today's rate, `currency` set to the current base).
- `GoalDto = { id, name, target, saved, remaining, percent, monthly, status, deadline, accountId, currency }`: `remaining = max(target − saved, 0)`; `percent = floor(saved / target × 100)`, not capped (the UI caps the bar); `status` is `reached` when saved ≥ target, `overdue` when the deadline month has passed and the goal is not reached, `active` otherwise; `monthly = ceil(remaining / monthsLeft)` in minor units, `null` without a deadline, when reached or when overdue; months left = (deadline year × 12 + month) − (current year × 12 + month), at least 1 in the deadline month itself.
- `GET /v1/goals` → `Page<GoalDto> & { currency, summary: { saved, monthly, active } }`, default and max page size 100, creation order. `summary.saved` = sum of saved over all goals; `summary.active` = goals not reached; `summary.monthly` = sum of contributions dated after today minus three calendar months and not after today (base amounts re-priced at the contribution date when the base currency changed) divided by 3, rounded to a minor unit.
- Goal validation: name required after trim, at most 40 characters (`validation.nameTooLong`); target a positive safe integer at most `100_000_000_000` (`validation.positiveAmount` / `validation.invalidValue`); deadline optional `YYYY-MM`, the current month or later (`validation.deadlinePast`), at most 600 months ahead (`validation.invalidValue`), an unchanged deadline is accepted on PUT; linked account optional, own (`validation.unknownAccount`), `savings` (`validation.savingsAccountOnly`), not archived (`validation.archivedAccount`), an unchanged link is accepted on PUT; several goals may link one account.
- Contribution `POST /v1/goals/{id}/contributions` `{ amount, date, fromAccountId?, rate? }` → the updated `GoalDto`. Date required, ISO, at most one year ahead (`validation.dateTooFar`); amount a positive safe integer at most `100_000_000_000`. With a linked account: `fromAccountId` required, own and active, different from the linked account (`validation.sameAccount`); the linked account must be active (`accountId: validation.archivedAccount`); `amount` is in the from-account currency and a transfer row exactly like `POST /v1/transfers` is stored (rate 1 for one currency, the client `rate` across currencies, else `rateOn`; note = goal name); saved grows by the transfer's `toAmount` converted from the linked account's currency into the base currency at the contribution date's rate. Without a linked account: `amount` is in the goal's base currency, `fromAccountId` is optional and only recorded (own and active when given), no balance moves. Contributions to reached goals are allowed.
- Contribution row = `{ id, userId, goalId, date, amount, currency, fromAccountId, transferId, baseAmount, baseCurrency }`.
- Deleting a goal deletes its contributions; transfers created by contributions stay. Deleting an account (possible only while unused) unlinks the goals that reference it. `AccountDto.linkedGoals` counts the user's goals linking the account.
- Invalidation: `goals` → `[['goals'], ['accounts'], ['overview']]`, `goalContributions` → `[['goals'], ['accounts'], ['transfers'], ['overview']]`; `settings` and `accounts` also invalidate `['goals']`.
- Every user-facing string goes through i18n with keys in `en`, `pl`, `ru`, `uk` (the parity test enforces it); keys are camelCase; dates and money go through `d()` / `n()`; month names come from the shared `useMonthLabel`.
- The UI never shows `ApiError.title` raw: unknown errors map by status (`useNotify().error`), field errors are shown through their i18n keys.
- Data queries run on the client only in mock mode — no `suspense()` or server prefetch.
- Accessibility: semantic elements, labels for every input, `aria-invalid` + `aria-describedby` on invalid fields, focus moves to the first invalid field on submit, touch targets at least 44px, duplicated desktop/mobile controls are hidden with `display: none` so only one is exposed.
- Only libraries from `docs/STACK.md`; PrimeVue stays on 4.x; components use design tokens, never raw hex values; amounts and percentages use `font-mono`.
- Code under `mocks/`, `app/shared/api/{contract,invalidation}.ts`, `app/shared/period`, `app/features/goals/utils` and `app/features/goals/schemas` uses plain relative imports (no Nuxt auto-imports, no `~` alias) so it runs in Bun.
- Biome (`bun run lint`) and `nuxt typecheck` (0 `error TS` lines) must pass before every commit.

## Review Focus

- A contribution to a linked goal is a real transfer: balances, the transfers list and `GET /v1/transfers` include it, the transfer survives deleting the goal, and `POST /v1/transfers` still behaves exactly as before the extraction. Pinned in Task 1 and Task 5 (E2E).
- Cross-currency contributions: the amount is in the from-account currency, the rate is the client's or the date's, and saved grows by the received amount valued in the base currency at the contribution date (also for a linked account in a foreign currency). Pinned in Task 1 and Task 5.
- Changing the base currency after goals exist: reads convert at today's rate, PUT and contributions re-base the row, the monthly summary re-prices each contribution at its date. Pinned in Task 1.
- Deadline rules: the current month is valid and gets a hint equal to the whole remainder; a past month is rejected except when unchanged on PUT, where the goal turns `overdue`; the hint rounds up. Pinned in Task 1 and Task 3.
- Seeded contributions: the emergency fund's history is the seeded card → savings transfers, so today's balances stay as designed and the monthly saving is exactly 1 400 zł on any seed day. Pinned in Task 2.
- Mobile layout: compact cards keep both Contribute and Edit reachable; the summary cards and the add tile are desktop-only, the saved total moves into the header caption. Pinned in Task 4 and Task 5 (E2E on both projects).

## Decisions taken for this stage

- Base currency: goal rows keep the base currency their amounts are stored in and are converted at today's rate on read; any PUT and any contribution store target and saved in the current base currency (mirrors budgets and transactions).
- Deadline is a month (`YYYY-MM`). It is valid from the current calendar month up to 600 months ahead; an unchanged past deadline is accepted on PUT. The months left count at least 1 in the deadline month.
- Hint `monthly = ceil(remaining / monthsLeft)`; `null` without a deadline, when reached or when the deadline month has passed. `status` (`active` / `reached` / `overdue`) drives the card texts "Goal reached", "The deadline has passed, X to go" and "No deadline — any amount helps".
- `percent` is floored and not capped; the progress bar caps itself at a full track.
- The summary's "monthly saving" is what the user actually saved: contributions of the last three calendar months divided by 3 (the sum of hints would be a plan, not a fact). The seed reproduces the design's 1 400 zł.
- Contributions to a linked goal create a transfer through the same code as `POST /v1/transfers` (rate rules, note = goal name); contributions to an unlinked goal only grow `saved` and record the optional source account.
- Linked accounts must be own active savings accounts; several goals may share one. An unchanged link stays valid on PUT even if the account was archived or changed type later; contributions are then refused with `accountId: validation.archivedAccount` and the dialog explains it.
- Deleting a goal deletes its contributions and keeps the transfers; deleting an (unused) account unlinks its goals. `AccountDto.linkedGoals` lets the accounts screen show "Linked to goals".
- Goal name length is 40 characters so the existing `validation.nameTooLong` message ("at most 40 characters") stays true.
- The card shows "Deadline: June 2027" instead of "Until June 2027": `d()` gives nominative month names, which read wrong after "do" / "до" in pl, ru and uk.
- A contribution re-bases the goal row into the current base currency before adding to it, like PUT.
- Seed: Anna's emergency fund (linked to her savings account) is fed by the four seeded card → savings transfers (their note becomes the goal name, the oldest grows to 3 200 zł, opening balances of the card and the savings account absorb the 2 200 zł so today's balances stay as designed); the two other goals are unlinked. Oleh's laptop goal is fed by his two seeded card → USD savings transfers (notes renamed to the goal name); his bike goal is reached.
- Mobile: the summary cards and the dashed tile are hidden; the header caption shows "Saved X" and a 44px "New goal" icon button; each compact card has a 44px pencil button ("Edit {name}") next to "Contribute".
- Reached goals show a "Reached" badge, a full bar and the "Goal reached" hint; contributions stay possible.
- The deadline input is a PrimeVue `DatePicker` in month view with a clear icon (no deadline = empty) and a localized `mm/yy` (`mm.yy`) input format.
- No screen composable: the page reads `useGoals()` directly and each dialog reads the shared accounts list itself.

type Errors = ReturnType<typeof collectErrors>

export function checkAccount(
  state: MockState,
  userId: string,
  value: unknown,
  field: string,
  errors: Errors,
): AccountRow | undefined {
  if (isMissing(value)) {
    errors.add(field, 'validation.required')
    return undefined
  }
  const account = state.accounts.find((row) => row.id === value && row.userId === userId)
  if (!account) errors.add(field, 'validation.unknownAccount')
  else if (account.archived) errors.add(field, 'validation.archivedAccount')
  return account
}

export type TransferDraft = {
  date: string
  from: AccountRow
  to: AccountRow
  fromAmount: number
  rate: number | undefined
  note: string | null
}

export function transferRow(state: MockState, userId: string, draft: TransferDraft): TransferRow {
  const rate =
    draft.from.currency === draft.to.currency
      ? 1
      : draft.rate !== undefined
        ? roundRate(draft.rate)
        : rateOn(state.rates, draft.date, draft.from.currency, draft.to.currency)
  const toAmount = convertMinor(draft.fromAmount, rate)
  if (toAmount <= 0) badRequest({ rate: ['validation.positiveAmount'] })
  return {
    id: newId('trf'),
    userId,
    date: draft.date,
    fromAccountId: draft.from.id,
    toAccountId: draft.to.id,
    fromAmount: draft.fromAmount,
    toAmount,
    rate,
    note: draft.note,
  }
}

import type { TransferDto } from '../../app/shared/api/contract'
import { isIsoDate, todayIso } from '../../app/shared/period/period'
import type { AccountRow, MockDb, TransferRow } from '../db'
import { paginate } from '../paginate'
import type { MockRouter } from '../router'
import { AMOUNT_MAX, checkAccount, transferRow } from '../transfers'
import { collectErrors, isMissing, objectBody } from '../validation'

export const TRANSFER_NOTE_MAX = 200

export const oneYearAhead = (today: string): string => `${Number(today.slice(0, 4)) + 1}${today.slice(4)}`

function createTransfer(db: MockDb, userId: string, body: unknown): TransferRow {
  const { date, fromAccountId, toAccountId, fromAmount, rate, note } = objectBody(body)
  const errors = collectErrors()
  if (isMissing(date)) errors.add('date', 'validation.required')
  else if (!isIsoDate(date)) errors.add('date', 'validation.invalidValue')
  else if (date > oneYearAhead(todayIso())) errors.add('date', 'validation.dateTooFar')
  const from = checkAccount(db.state, userId, fromAccountId, 'fromAccountId', errors)
  const to = checkAccount(db.state, userId, toAccountId, 'toAccountId', errors)
  if (from && to && from.id === to.id) errors.add('toAccountId', 'validation.sameAccount')
  if (isMissing(fromAmount)) errors.add('fromAmount', 'validation.required')
  else if (!Number.isSafeInteger(fromAmount) || (fromAmount as number) > AMOUNT_MAX) {
    errors.add('fromAmount', 'validation.invalidValue')
  } else if ((fromAmount as number) <= 0) errors.add('fromAmount', 'validation.positiveAmount')
  if (!isMissing(rate) && (typeof rate !== 'number' || !Number.isFinite(rate) || rate <= 0)) {
    errors.add('rate', 'validation.invalidValue')
  }
  if (!isMissing(note) && (typeof note !== 'string' || note.trim().length > TRANSFER_NOTE_MAX)) {
    errors.add('note', 'validation.invalidValue')
  }
  errors.throwIfAny()
  return transferRow(db.state, userId, {
    date: date as string,
    from: from as AccountRow,
    to: to as AccountRow,
    fromAmount: fromAmount as number,
    rate: typeof rate === 'number' ? rate : undefined,
    note: typeof note === 'string' && note.trim() !== '' ? note.trim() : null,
  })
}

const newestFirst = (rows: readonly TransferRow[]): TransferRow[] =>
  rows
    .map((row, index) => ({ row, index }))
    .sort((a, b) => b.row.date.localeCompare(a.row.date) || b.index - a.index)
    .map(({ row }) => row)

const toDto = ({ userId: _userId, ...row }: TransferRow): TransferDto => row

export function registerTransferHandlers(router: MockRouter) {
  router.on('GET', '/v1/transfers', ({ db, userId, query }) => {
    const own = db.state.transfers.filter(
      (row) =>
        row.userId === userId &&
        (query.accountId === undefined || row.fromAccountId === query.accountId || row.toAccountId === query.accountId),
    )
    return paginate(newestFirst(own).map(toDto), query, { defaultPageSize: 20, maxPageSize: 100 })
  })

  router.on('POST', '/v1/transfers', ({ db, userId, body }) => {
    const row = createTransfer(db, userId, body)
    db.state.transfers.push(row)
    db.save()
    return toDto(row)
  })

import type { GoalDto, GoalStatus, GoalSummary } from '../app/shared/api/contract'
import { type Currency, convertMinor } from '../app/shared/money/money'
import { shiftPeriod, toIsoDate } from '../app/shared/period/period'
import type { GoalContributionRow, GoalRow, MockState } from './db'
import { rateOn } from './rates'
import { baseCurrencyOf } from './transactions'

export const GOAL_DEADLINE_MAX_MONTHS = 600

export const SAVING_WINDOW_MONTHS = 3

export const monthKeyOf = (iso: string): string => iso.slice(0, 7)

export const addMonthsToKey = (key: string, months: number): string => shiftPeriod(key, months, 1).key

const monthIndex = (value: string): number => {
  const [year, month] = value.split('-').map(Number)
  return (year ?? 0) * 12 + (month ?? 1)
}

export const monthsUntil = (deadline: string, today: string): number => monthIndex(deadline) - monthIndex(today)

export function goalStatus(saved: number, target: number, deadline: string | null, today: string): GoalStatus {
  if (saved >= target) return 'reached'
  if (deadline !== null && monthsUntil(deadline, today) < 0) return 'overdue'
  return 'active'
}

export function monthlyHint(remaining: number, deadline: string | null, today: string): number | null {
  if (deadline === null || remaining <= 0) return null
  const months = monthsUntil(deadline, today)
  return months < 0 ? null : Math.ceil(remaining / Math.max(months, 1))
}

export function monthsBefore(iso: string, months: number): string {
  const [year, month, day] = iso.split('-').map(Number)
  const first = new Date(Date.UTC(year ?? 0, (month ?? 1) - 1 - months, 1))
  const lastDay = new Date(Date.UTC(first.getUTCFullYear(), first.getUTCMonth() + 1, 0)).getUTCDate()
  return toIsoDate(new Date(Date.UTC(first.getUTCFullYear(), first.getUTCMonth(), Math.min(day ?? 1, lastDay))))
}

export const amountIn = (state: MockState, amount: number, from: Currency, to: Currency, date: string): number =>
  from === to ? amount : convertMinor(amount, rateOn(state.rates, date, from, to))

export function rebaseGoal(state: MockState, row: GoalRow, base: Currency, today: string): void {
  if (row.currency === base) return
  row.target = amountIn(state, row.target, row.currency, base, today)
  row.saved = amountIn(state, row.saved, row.currency, base, today)
  row.currency = base
}

export function goalView(state: MockState, row: GoalRow, base: Currency, today: string): GoalDto {
  const target = amountIn(state, row.target, row.currency, base, today)
  const saved = amountIn(state, row.saved, row.currency, base, today)
  const remaining = Math.max(target - saved, 0)
  return {
    id: row.id,
    name: row.name,
    target,
    saved,
    remaining,
    percent: target > 0 ? Math.floor((saved * 100) / target) : 0,
    monthly: monthlyHint(remaining, row.deadline, today),
    status: goalStatus(saved, target, row.deadline, today),
    deadline: row.deadline,
    accountId: row.accountId,
    currency: base,
  }
}

export function goalsOf(state: MockState, userId: string, today: string): GoalDto[] {
  const base = baseCurrencyOf(state, userId)
  return state.goals.filter((row) => row.userId === userId).map((row) => goalView(state, row, base, today))
}

export const contributionValue = (state: MockState, row: GoalContributionRow, base: Currency): number =>
  amountIn(state, row.baseAmount, row.baseCurrency, base, row.date)

export function summarizeGoals(
  state: MockState,
  userId: string,
  goals: readonly GoalDto[],
  today: string,
): GoalSummary {
  const base = baseCurrencyOf(state, userId)
  const since = monthsBefore(today, SAVING_WINDOW_MONTHS)
  const recent = state.goalContributions
    .filter((row) => row.userId === userId && row.date > since && row.date <= today)
    .reduce((sum, row) => sum + contributionValue(state, row, base), 0)
  return {
    saved: goals.reduce((sum, goal) => sum + goal.saved, 0),
    monthly: Math.round(recent / SAVING_WINDOW_MONTHS),
    active: goals.filter((goal) => goal.status !== 'reached').length,
  }
}

export function linkedGoalCounts(state: MockState, userId: string): Map<string, number> {
  const counts = new Map<string, number>()
  for (const row of state.goals) {
    if (row.userId !== userId || row.accountId === null) continue
    counts.set(row.accountId, (counts.get(row.accountId) ?? 0) + 1)
  }
  return counts
}

export function unlinkAccount(state: MockState, userId: string, accountId: string): void {
  for (const row of state.goals) {
    if (row.userId === userId && row.accountId === accountId) row.accountId = null
  }
}

export const GOAL_NAME_MAX = 40

type Errors = ReturnType<typeof collectErrors>
type GoalFields = Pick<GoalRow, 'name' | 'target' | 'deadline' | 'accountId'>

function checkAmount(value: unknown, field: string, errors: Errors): void {
  if (isMissing(value)) errors.add(field, 'validation.required')
  else if (!Number.isSafeInteger(value) || (value as number) > AMOUNT_MAX) errors.add(field, 'validation.invalidValue')
  else if ((value as number) <= 0) errors.add(field, 'validation.positiveAmount')
}

function checkDeadline(value: unknown, today: string, errors: Errors, existing?: GoalRow): void {
  if (isMissing(value)) return
  if (!isPeriodKey(value)) {
    errors.add('deadline', 'validation.invalidValue')
    return
  }
  if (value === existing?.deadline) return
  const current = monthKeyOf(today)
  if (value < current) errors.add('deadline', 'validation.deadlinePast')
  else if (value > addMonthsToKey(current, GOAL_DEADLINE_MAX_MONTHS)) errors.add('deadline', 'validation.invalidValue')
}

function checkLinkedAccount(db: MockDb, userId: string, value: unknown, errors: Errors, existing?: GoalRow): void {
  if (isMissing(value)) return
  const account = db.state.accounts.find((row) => row.id === value && row.userId === userId)
  if (!account) {
    errors.add('accountId', 'validation.unknownAccount')
    return
  }
  if (account.id === existing?.accountId) return
  if (account.type !== 'savings') errors.add('accountId', 'validation.savingsAccountOnly')
  else if (account.archived) errors.add('accountId', 'validation.archivedAccount')
}

function validateGoal(db: MockDb, userId: string, body: unknown, today: string, existing?: GoalRow): GoalFields {
  const { name, target, deadline, accountId } = objectBody(body)
  const errors = collectErrors()
  if (isMissing(name)) errors.add('name', 'validation.required')
  else if (typeof name !== 'string') errors.add('name', 'validation.invalidValue')
  else if (name.trim().length > GOAL_NAME_MAX) errors.add('name', 'validation.nameTooLong')
  checkAmount(target, 'target', errors)
  checkDeadline(deadline, today, errors, existing)
  checkLinkedAccount(db, userId, accountId, errors, existing)
  errors.throwIfAny()
  return {
    name: (name as string).trim(),
    target: target as number,
    deadline: isMissing(deadline) ? null : (deadline as string),
    accountId: isMissing(accountId) ? null : (accountId as string),
  }
}

function recordContribution(
  db: MockDb,
  userId: string,
  goal: GoalRow,
  body: unknown,
  today: string,
): GoalContributionRow {
  const { amount, date, fromAccountId, rate } = objectBody(body)
  const errors = collectErrors()
  if (isMissing(date)) errors.add('date', 'validation.required')
  else if (!isIsoDate(date)) errors.add('date', 'validation.invalidValue')
  else if (date > oneYearAhead(today)) errors.add('date', 'validation.dateTooFar')
  checkAmount(amount, 'amount', errors)
  if (!isMissing(rate) && (typeof rate !== 'number' || !Number.isFinite(rate) || rate <= 0)) {
    errors.add('rate', 'validation.invalidValue')
  }
  const linked =
    goal.accountId === null
      ? undefined
      : db.state.accounts.find((row) => row.id === goal.accountId && row.userId === userId)
  if (goal.accountId !== null && (!linked || linked.archived)) errors.add('accountId', 'validation.archivedAccount')
  const from =
    goal.accountId !== null || !isMissing(fromAccountId)
      ? checkAccount(db.state, userId, fromAccountId, 'fromAccountId', errors)
      : undefined
  if (from && linked && from.id === linked.id) errors.add('fromAccountId', 'validation.sameAccount')
  errors.throwIfAny()
  const day = date as string
  const value = amount as number
  const base = baseCurrencyOf(db.state, userId)
  const id = newId('gcn')
  if (!linked) {
    return {
      id,
      userId,
      goalId: goal.id,
      date: day,
      amount: value,
      currency: base,
      fromAccountId: from?.id ?? null,
      transferId: null,
      baseAmount: value,
      baseCurrency: base,
    }
  }
  const source = from as AccountRow
  const transfer = transferRow(db.state, userId, {
    date: day,
    from: source,
    to: linked,
    fromAmount: value,
    rate: typeof rate === 'number' ? rate : undefined,
    note: goal.name,
  })
  db.state.transfers.push(transfer)
  return {
    id,
    userId,
    goalId: goal.id,
    date: day,
    amount: value,
    currency: source.currency,
    fromAccountId: source.id,
    transferId: transfer.id,
    baseAmount: amountIn(db.state, transfer.toAmount, linked.currency, base, day),
    baseCurrency: base,
  }
}

const ownGoal = (db: MockDb, userId: string, id: string | undefined): GoalRow =>
  db.state.goals.find((row) => row.id === id && row.userId === userId) ?? notFound()

export function registerGoalHandlers(router: MockRouter) {
  router.on('GET', '/v1/goals', ({ db, userId, query }): GoalPage => {
    const today = todayIso()
    const goals = goalsOf(db.state, userId, today)
    return {
      ...paginate(goals, query, { defaultPageSize: 100, maxPageSize: 100 }),
      currency: baseCurrencyOf(db.state, userId),
      summary: summarizeGoals(db.state, userId, goals, today),
    }
  })

  router.on('POST', '/v1/goals', ({ db, userId, body }) => {
    const today = todayIso()
    const base = baseCurrencyOf(db.state, userId)
    const row: GoalRow = {
      id: newId('goal'),
      userId,
      saved: 0,
      currency: base,
      createdAt: new Date().toISOString(),
      ...validateGoal(db, userId, body, today),
    }
    db.state.goals.push(row)
    db.save()
    return goalView(db.state, row, base, today)
  })

  router.on('PUT', '/v1/goals/:id', ({ db, userId, params, body }) => {
    const row = ownGoal(db, userId, params.id)
    const today = todayIso()
    const base = baseCurrencyOf(db.state, userId)
    const fields = validateGoal(db, userId, body, today, row)
    rebaseGoal(db.state, row, base, today)
    Object.assign(row, fields)
    db.save()
    return goalView(db.state, row, base, today)
  })

  router.on('DELETE', '/v1/goals/:id', ({ db, userId, params }) => {
    const row = ownGoal(db, userId, params.id)
    db.state.goals = db.state.goals.filter((goal) => goal.id !== row.id)
    db.state.goalContributions = db.state.goalContributions.filter((contribution) => contribution.goalId !== row.id)
    db.save()
  })

  router.on('POST', '/v1/goals/:id/contributions', ({ db, userId, params, body }) => {
    const goal = ownGoal(db, userId, params.id)
    const today = todayIso()
    const contribution = recordContribution(db, userId, goal, body, today)
    rebaseGoal(db.state, goal, contribution.baseCurrency, today)
    goal.saved += contribution.baseAmount
    db.state.goalContributions.push(contribution)
    db.save()
    return goalView(db.state, goal, contribution.baseCurrency, today)
  })
}

  for (const plan of plans) {

                baseCurrency: base,
              }

    goals.push({
      id,
      userId: plan.userId,
      name: plan.name,
      target: plan.target,
      saved: drafts.reduce((sum, draft) => sum + draft.baseAmount, 0),
      currency: base,
      deadline: plan.deadlineIn === null ? null : addMonthsToKey(monthKeyOf(today), plan.deadlineIn),
      accountId: linked,
      createdAt: `${addDaysIso(today, -175)}T09:00:00Z`,
    })
    contributions.push(
      ...drafts.map(
        (draft, index): GoalContributionRow => ({
          id: `gcn_seed_${plan.short}_${plan.key}_${index + 1}`,
          userId: plan.userId,
          goalId: id,
          ...draft,
        }),
      ),
    )
  }
  return { goals, contributions }
}

export type GoalHint = { key: string; amount: number | null }

export function goalHint(goal: Pick<GoalDto, 'status' | 'remaining' | 'monthly'>): GoalHint {
  if (goal.status === 'reached') return { key: 'goals.hint.reached', amount: null }
  if (goal.status === 'overdue') return { key: 'goals.hint.overdue', amount: goal.remaining }
  if (goal.monthly !== null) return { key: 'goals.hint.monthly', amount: goal.monthly }
  return { key: 'goals.hint.noDeadline', amount: null }
}

export const savedShare = (saved: number, target: number): number => (target > 0 ? Math.min(saved / target, 1) : 0)

export const monthKeyOfDate = (date: Date): string =>
  `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}`

export const dateOfMonthKey = (key: string): Date => {
  const [year, month] = key.split('-').map(Number)
  return new Date(year ?? 0, (month ?? 1) - 1, 1)
}

export const linkableAccounts = (accounts: readonly AccountDto[], currentId: string | null): AccountDto[] =>
  accounts.filter((account) => account.id === currentId || (account.type === 'savings' && !account.archived))

export const contributionSources = (accounts: readonly AccountDto[], linkedId: string | null): AccountDto[] =>
  accounts.filter((account) => !account.archived && account.id !== linkedId)

export function receivedAmount(amount: number | null, rate: number | null): number | undefined {
  if (amount === null || amount <= 0 || rate === null || rate <= 0) return undefined

import { monthKeyOfDate } from '../utils/goalView'

export const GOAL_NAME_MAX = 40

export const GOAL_TARGET_MAX = 1_000_000_000

export type GoalForm = { name: string; target: number | null; deadline: Date | null; accountId: string | null }

type Translate = (key: string) => string

export const hasText = (value: unknown): boolean => typeof value === 'string' && value.trim() !== ''

export const isNameWithinMax = (value: unknown): boolean =>
  typeof value !== 'string' || value.trim().length <= GOAL_NAME_MAX

export const isPositiveAmount = (value: unknown): boolean =>
  value === null || value === undefined || (typeof value === 'number' && value > 0)

export const isWithinMax =
  (max: number) =>
  (value: unknown): boolean =>
    typeof value !== 'number' || value <= max

export const isDeadlineAllowed =
  (minMonth: () => string, original: () => string | null) =>
  (value: unknown): boolean => {
    if (!(value instanceof Date)) return true
    const key = monthKeyOfDate(value)
    return key >= minMonth() || key === original()
  }

export const goalRules = (
  t: Translate,
  options: { minMonth: () => string; originalDeadline: () => string | null },
) => ({
  name: {
    required: helpers.withMessage(() => t('validation.required'), hasText),
    maxLength: helpers.withMessage(() => t('validation.nameTooLong'), isNameWithinMax),
  },
  target: {
    required: helpers.withMessage(() => t('validation.required'), required),
    positive: helpers.withMessage(() => t('validation.positiveAmount'), isPositiveAmount),
    max: helpers.withMessage(() => t('validation.invalidValue'), isWithinMax(GOAL_TARGET_MAX)),
  },
  deadline: {
    notPast: helpers.withMessage(
      () => t('validation.deadlinePast'),
      isDeadlineAllowed(options.minMonth, options.originalDeadline),
    ),
  },
  accountId: {},
})

  fromAccountId: string | null

  (condition: () => boolean) =>
  (value: unknown): boolean =>
    !condition() || (value !== null && value !== undefined && value !== '')

export const contributionRules = (t: Translate, options: { linked: () => boolean; crossCurrency: () => boolean }) => {
  const requiredField = helpers.withMessage(() => t('validation.required'), required)

    date: { required: requiredField },
    rate: {
      required: helpers.withMessage(() => t('validation.required'), requiredWhen(options.crossCurrency)),
      positive: helpers.withMessage(() => t('validation.positiveAmount'), isPositiveAmount),
    },

const goalPath = (id: string) => `/v1/goals/${encodeURIComponent(id)}`

export const goalsApi = (api: ApiClient) => ({
  list: () => api.get<GoalPage>('/v1/goals', { pageSize: 100 }),
  create: (body: GoalInput) => api.post<GoalDto>('/v1/goals', body),
  update: (id: string, body: GoalInput) => api.put<GoalDto>(goalPath(id), body),
  remove: (id: string) => api.delete(goalPath(id)),
  contribute: (id: string, body: GoalContributionInput) => api.post<GoalDto>(`${goalPath(id)}/contributions`, body),
})
```

import { useMutation, useQueryClient } from '@tanstack/vue-query'
import type { GoalContributionInput, GoalInput } from '~/shared/api/contract'
import { invalidateAfter } from '~/shared/api/invalidation'
import { goalsApi } from '../api/goalsApi'

export function useGoalMutations() {
  const api = goalsApi(useApi())
  const queryClient = useQueryClient()
  const onSuccess = () => invalidateAfter(queryClient, 'goals')

  return {
    create: useMutation({ mutationFn: api.create, onSuccess }),
    update: useMutation({
      mutationFn: ({ id, input }: { id: string; input: GoalInput }) => api.update(id, input),
      onSuccess,
    }),
    remove: useMutation({ mutationFn: api.remove, onSuccess }),
    contribute: useMutation({
      mutationFn: ({ id, input }: { id: string; input: GoalContributionInput }) => api.contribute(id, input),
      onSuccess: () => invalidateAfter(queryClient, 'goalContributions'),
    }),
  }
}

import { useAccounts } from '~/shared/accounts/useAccounts'
import type { GoalDto, GoalInput } from '~/shared/api/contract'
import { type Currency, fromMinor, toMinor } from '~/shared/money/money'
import { todayIso } from '~/shared/period/period'
import { GOAL_TARGET_MAX, type GoalForm, goalRules } from '../schemas/goalSchema'
import { dateOfMonthKey, linkableAccounts, monthKeyOfDate } from '../utils/goalView'

const props = defineProps<{ goal?: GoalDto; currency: Currency }>()
const visible = defineModel<boolean>('visible', { required: true })
const { t, locale } = useI18n()
const notify = useNotify()
const confirm = useConfirm()
const server = useServerErrors()
const accounts = useAccounts()
const { create, update, remove } = useGoalMutations()

const fields = ['name', 'target', 'deadline', 'accountId'] as const
type Field = (typeof fields)[number]

const currentMonth = () => todayIso().slice(0, 7)
const form = reactive<GoalForm>({ name: '', target: null, deadline: null, accountId: null })
const v$ = useVuelidate(
  goalRules(t, { minMonth: currentMonth, originalDeadline: () => props.goal?.deadline ?? null }),
  form,
)
const formEl = ref<HTMLFormElement | null>(null)

const isEdit = computed(() => props.goal !== undefined)
const saving = computed(() => create.isPending.value || update.isPending.value || remove.isPending.value)
const minDate = computed(() => dateOfMonthKey(currentMonth()))
const accountOptions = computed(() =>
  linkableAccounts(accounts.accounts.value, props.goal?.accountId ?? null).map((account) => ({
    value: account.id,
    label: `${account.name} · ${account.currency}`,
  })),
)

function reset() {
  const goal = props.goal
  Object.assign(
    form,
    goal
      ? {
          name: goal.name,
          target: fromMinor(goal.target),
          deadline: goal.deadline ? dateOfMonthKey(goal.deadline) : null,
          accountId: goal.accountId,
        }
      : { name: '', target: null, deadline: null, accountId: null },
  )
  server.clear()
  v$.value.$reset()
}

watch(visible, (open) => {
  if (open) reset()
})

const errorsOf = (field: Field) => [
  ...v$.value[field].$errors.map((error) => String(unref(error.$message))),
  ...server.messages(field),
]

function touch(field: Field) {
  v$.value[field].$touch()
  server.clear(field)
}

const close = (message: string) => {
  notify.success(message)
  visible.value = false
}

async function showServerErrors(error: unknown) {
  if (server.apply(error, fields)) {
    await nextTick()
    focusFirstInvalid(formEl.value)
  } else notify.error(error)
}

async function submit() {
  server.clear()
  if (!(await v$.value.$validate())) {
    await nextTick()
    focusFirstInvalid(formEl.value)
    return
  }
  const input: GoalInput = {
    name: form.name.trim(),
    target: toMinor(form.target ?? 0),
    deadline: form.deadline ? monthKeyOfDate(form.deadline) : null,
    accountId: form.accountId,
  }
  const goal = props.goal
  if (goal) {
    update.mutate(
      { id: goal.id, input },
      { onSuccess: () => close(t('goals.toast.updated')), onError: showServerErrors },
    )
  } else {
    create.mutate(input, { onSuccess: () => close(t('goals.toast.created')), onError: showServerErrors })
  }
}

function confirmDelete() {
  const goal = props.goal
  if (!goal) return
  confirm.require({
    header: t('goals.confirm.deleteTitle'),
    message: t('goals.confirm.deleteMessage', { name: goal.name }),
    acceptLabel: t('goals.actions.delete'),
    rejectLabel: t('shared.actions.cancel'),
    acceptProps: { severity: 'danger' },
    rejectProps: { severity: 'secondary', outlined: true },
    accept: () =>
      remove.mutate(goal.id, {
        onSuccess: () => close(t('goals.toast.deleted')),
        onError: (error) => notify.error(error),
      }),
  })
}

<script setup lang="ts">
import { useVuelidate } from '@vuelidate/core'
import type { InputNumberInputEvent } from 'primevue/inputnumber'
import { useAccounts } from '~/shared/accounts/useAccounts'
import type { GoalContributionInput, GoalDto } from '~/shared/api/contract'
import { toMinor } from '~/shared/money/money'
import { addDaysIso, fromLocalDate, todayIso, toLocalDate } from '~/shared/period/period'
import { useRates } from '~/shared/rates/useRates'
import { CONTRIBUTION_AMOUNT_MAX, type ContributionForm, contributionRules } from '../schemas/contributionSchema'
import { contributionSources, receivedAmount } from '../utils/goalView'

const props = defineProps<{ goal: GoalDto }>()
const visible = defineModel<boolean>('visible', { required: true })
const { t, locale } = useI18n()
const { format } = useMoney()
const notify = useNotify()
const server = useServerErrors()
const accounts = useAccounts()
const { contribute } = useGoalMutations()

const fields = ['amount', 'fromAccountId', 'date', 'rate'] as const
type Field = (typeof fields)[number]

const form = reactive<ContributionForm>({
  amount: null,
  fromAccountId: null,
  date: toLocalDate(todayIso()),
  rate: null,
})
const formEl = ref<HTMLFormElement | null>(null)
const rateEdited = ref(false)

const isLinked = computed(() => props.goal.accountId !== null)
const accountsReady = computed(() => !accounts.isPending.value && !accounts.isError.value)
const linkedAccount = computed(() => accounts.accounts.value.find((account) => account.id === props.goal.accountId))
const linkedUnavailable = computed(
  () => isLinked.value && accountsReady.value && (!linkedAccount.value || linkedAccount.value.archived),
)
const sources = computed(() => contributionSources(accounts.accounts.value, props.goal.accountId))
const fromAccount = computed(() => sources.value.find((account) => account.id === form.fromAccountId))
const crossCurrency = computed(
  () => !!fromAccount.value && !!linkedAccount.value && fromAccount.value.currency !== linkedAccount.value.currency,
)
const amountCurrency = computed(() => (isLinked.value ? fromAccount.value?.currency : undefined) ?? props.goal.currency)
const v$ = useVuelidate(
  contributionRules(t, { linked: () => isLinked.value, crossCurrency: () => crossCurrency.value }),
  form,
)

const rateDate = computed(() => (form.date ? fromLocalDate(form.date) : todayIso()))
const rates = useRates(() => linkedAccount.value?.currency ?? props.goal.currency, {
  date: rateDate,
  enabled: crossCurrency,
})
const suggestedRate = computed(() =>
  fromAccount.value && crossCurrency.value ? rates.rateFrom(fromAccount.value.currency) : undefined,
)

watch(suggestedRate, (rate) => {
  if (rate !== undefined && !rateEdited.value) form.rate = rate
})

watch([() => fromAccount.value?.currency, () => linkedAccount.value?.currency], () => {
  rateEdited.value = false
  form.rate = suggestedRate.value ?? null
})

watch(sources, (list) => {
  if (visible.value && isLinked.value && form.fromAccountId === null) form.fromAccountId = list[0]?.id ?? null
})

const sourceOptions = computed(() =>
  sources.value.map((account) => ({ value: account.id, label: `${account.name} · ${account.currency}` })),
)
const maxDate = computed(() => toLocalDate(addDaysIso(todayIso(), 365)))
const preview = computed(() => {
  if (!isLinked.value) return t('goals.contribute.noTransfer')
  if (!fromAccount.value || !linkedAccount.value) return undefined
  return t('goals.contribute.transfer', { from: fromAccount.value.name, to: linkedAccount.value.name })
})
const receives = computed(() => {
  if (!crossCurrency.value || !linkedAccount.value) return undefined
  const amount = receivedAmount(form.amount, form.rate)
  return amount === undefined
    ? undefined
    : t('goals.contribute.receives', { amount: format(amount, linkedAccount.value.currency) })
})
const rateCurrencies = computed(() => ({
  from: fromAccount.value?.currency ?? '',
  to: linkedAccount.value?.currency ?? '',
}))

const numberOrNull = (value: unknown) => (typeof value === 'number' ? value : null)

function reset() {
  Object.assign(form, {
    amount: null,
    fromAccountId: isLinked.value ? (sources.value[0]?.id ?? null) : null,
    date: toLocalDate(todayIso()),
  })
  rateEdited.value = false
  form.rate = suggestedRate.value ?? null
  server.clear()
  v$.value.$reset()
}

watch(
  visible,
  (open) => {
    if (open) reset()
  },
  { immediate: true },
)

const errorsOf = (field: Field) => [
  ...v$.value[field].$errors.map((error) => String(unref(error.$message))),
  ...server.messages(field),
]

function touch(field: Field) {
  v$.value[field].$touch()
  server.clear(field)
}

function onAmountInput(event: InputNumberInputEvent) {
  form.amount = numberOrNull(event.value)
}

function onRateInput(event: InputNumberInputEvent) {
  rateEdited.value = true
  form.rate = numberOrNull(event.value)
}

async function submit() {
  server.clear()
  if (!(await v$.value.$validate())) {
    await nextTick()
    focusFirstInvalid(formEl.value)
    return
  }
  const input: GoalContributionInput = {
    amount: toMinor(form.amount ?? 0),
    date: fromLocalDate(form.date as Date),
    ...(form.fromAccountId ? { fromAccountId: form.fromAccountId } : {}),
    ...(crossCurrency.value && form.rate !== null ? { rate: form.rate } : {}),
  }
  contribute.mutate(
    { id: props.goal.id, input },
    {
      onSuccess: () => {
        notify.success(t('goals.toast.contributed'))
        visible.value = false
      },
      onError: async (error) => {
        if (server.apply(error, fields)) {
          await nextTick()
          focusFirstInvalid(formEl.value)
        } else notify.error(error)
      },
    },
  )
}
</script>

<template>
  <Dialog
    v-model:visible="visible"
    modal
    :header="t('goals.contribute.title', { name: goal.name })"
    class="w-[calc(100vw-2rem)] max-w-[30rem]"
  >
    <p v-if="linkedUnavailable" role="alert" class="m-0 text-sm text-muted">
      {{ t('goals.contribute.linkedUnavailable') }}
    </p>
    <form v-else id="contribution-form" ref="formEl" class="flex flex-col gap-4" novalidate @submit.prevent="submit">
      <FormRow id="contribution-amount" :label="t('goals.contribute.amount')" :errors="errorsOf('amount')">
        <template #default="{ invalid, describedBy }">
          <InputNumber
            v-model="form.amount"
            input-id="contribution-amount"
            mode="currency"
            :currency="amountCurrency"
            :locale="locale"
            :min-fraction-digits="2"
            :max-fraction-digits="2"
            :min="0"
            :max="CONTRIBUTION_AMOUNT_MAX"
            :invalid="invalid"
            :pt="{ pcInputText: { root: { 'aria-describedby': describedBy, 'aria-invalid': invalid || undefined } } }"
            fluid
            @input="onAmountInput"
            @blur="touch('amount')"
          />
        </template>
      </FormRow>
      <FormRow id="contribution-from" :label="t('goals.contribute.from')" :errors="errorsOf('fromAccountId')">
        <template #default="{ invalid, describedBy, labelId }">
          <Select
            v-model="form.fromAccountId"
            input-id="contribution-from"
            :options="sourceOptions"
            option-label="label"
            option-value="value"
            :placeholder="isLinked ? undefined : t('goals.contribute.fromPlaceholder')"
            :show-clear="!isLinked"
            :loading="accounts.isPending.value"
            :invalid="invalid"
            :aria-labelledby="labelId"
            :pt="{ label: { 'aria-describedby': describedBy, 'aria-invalid': invalid || undefined } }"
            fluid
            @change="touch('fromAccountId')"
          />
        </template>
      </FormRow>
      <FormRow id="contribution-date" :label="t('goals.contribute.date')" :errors="errorsOf('date')">
        <template #default="{ invalid, describedBy }">
          <DatePicker
            v-model="form.date"
            input-id="contribution-date"
            :date-format="t('shared.dateInputFormat')"
            :max-date="maxDate"
            :invalid="invalid"
            :pt="{ pcInputText: { root: { 'aria-describedby': describedBy, 'aria-invalid': invalid || undefined } } }"
            show-icon
            fluid
            @blur="touch('date')"
          />
        </template>
      </FormRow>
      <FormRow
        v-if="crossCurrency"
        id="contribution-rate"
        :label="t('goals.contribute.rate', rateCurrencies)"
        :errors="errorsOf('rate')"
        :hint="t('goals.contribute.rateHint', rateCurrencies)"
      >
        <template #default="{ invalid, describedBy }">
          <InputNumber
            v-model="form.rate"
            input-id="contribution-rate"
            :locale="locale"
            :min-fraction-digits="2"
            :max-fraction-digits="6"
            :min="0"
            :invalid="invalid"
            :pt="{ pcInputText: { root: { 'aria-describedby': describedBy, 'aria-invalid': invalid || undefined } } }"
            fluid
            @input="onRateInput"
            @blur="touch('rate')"
          />
        </template>
      </FormRow>
      <p v-if="preview" class="m-0 text-sm text-muted" aria-live="polite">{{ preview }}</p>
      <p v-if="receives" class="m-0 font-mono text-sm text-muted" aria-live="polite">{{ receives }}</p>
    </form>
    <template #footer>
      <Button :label="t('shared.actions.cancel')" severity="secondary" outlined @click="visible = false" />
      <Button
        v-if="!linkedUnavailable"
        type="submit"
        form="contribution-form"
        :label="t('shared.actions.save')"
        :loading="contribute.isPending.value"
        :disabled="contribute.isPending.value || !accountsReady"
      />
    </template>
  </Dialog>
</template>
```

The page mounts this dialog on the first "Contribute" click (`v-if="contributing"`) with `visible` already `true`, which is why its reset watcher runs with `immediate: true`; the `sources` watcher picks the first source account once the accounts arrive.

## What changed and why

Goals now work end to end on the mock backend. A goal has a target in the base currency, an optional deadline month and an optional linked savings account. The list endpoint returns what the screen needs in one go: saved, remaining, percent, a status (active, reached, overdue), the "save X per month" hint for goals with a deadline, and a summary with the saved total, the average monthly saving of the last three months and the number of active goals.

- A contribution to a goal with a linked savings account is recorded as a real transfer (same rules as the transfer dialog, including a corrected exchange rate for cross-currency transfers), so balances and the transfers list follow. Without a link a contribution only grows the goal.
- The deadline is a month; it cannot be in the past, and an existing past deadline turns the goal overdue instead of blocking edits.
- Changing the base currency converts goals at today's rate; editing or contributing stores them in the new currency.
- Deleting a goal keeps the transfers it created; deleting an unused account unlinks its goals. Accounts report how many goals link them, and the accounts screen shows "Linked to goals" on such a savings card.
- Both demo users get goals with contribution history; Anna's match the design (14 300 zł saved, 1 400 zł a month, three active goals), Oleh has a linked, an open-ended and a reached goal.
- The `/goals` screen has the summary cards, goal cards with progress and hints, the dashed "New goal" tile, the new/edit/delete dialog and the contribution dialog; mobile shows compact cards with "Contribute" and an edit button, and the saved total in the header.
- The three copies of the month label code are replaced by one shared `useMonthLabel`.

## How to test

1. `bun run dev`, open `/goals`: three goals, 14,300.00 PLN saved, 1,400.00 PLN a month.

3. Contribute from "Konto EUR" and correct the exchange rate; contribute to "Wakacje" (no transfer is created).
